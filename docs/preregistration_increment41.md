# Пре-регистрация инкремента 41: функциональные пробы по меткам записи (реактивность)

Зафиксировано до запуска на данных. Код: `layer3_features/procedures.py` (D75),
скрипт `scripts/run_eegmmidb_reactivity.py`.

## Что проверяется

Модуль проб распознаёт метки «глаза закрыты/открыты», ГВ, ФС и считает: основной ритм на
участках с закрытыми глазами (`ec_pdr_hz`) и реактивность — подавление заднего альфа-ритма при
открывании глаз `1 − P_откр / P_закр` (порог «реактивен» ≥ 0.5, задан в коде до проверки).

## Данные

PhysioNet EEG Motor Movement/Imagery (EEGMMIDB, Schalk и соавт., BCI2000): 109 здоровых
добровольцев, 64 канала 10-10, 160 Гц. У каждого — две минутные базовые записи: R01 (глаза
открыты) и R02 (глаза закрыты). Меток внутри записи нет, поэтому запись склеивается так, как
идёт клиническая проба: R02, затем R01, с метками «Eyes closed» в 0 с и «Eyes open» в начале R01.
Предобработка — та же, что в конвейере (фильтры, усреднённый референт), отдельно для каждой части.
Набор не использовался ни для разработки, ни для порогов.

## Гипотезы и правила решения

* **H1 (реактивность):** у здоровых взрослых альфа-ритм подавляется при открывании глаз.
  Ожидание: доля «реактивен» ≥ 0.70, медиана подавления ≥ 0.5.
* **H2 (ритм с закрытыми глазами):** `ec_pdr_hz` найден (> 0) не менее чем у 80% и у них лежит
  в 8–13 Гц не менее чем у 90%.

Решение:
* H1 и H2 выполнены → модуль включается в отчёт как описательный (уже так в коде).
* Доля «реактивен» < 0.50 → метод пересматривается (полоса, окна), модуль из отчёта убирается до
  повторной проверки на других данных.
* Между 0.50 и 0.70 → модуль остаётся описательным, ограничение указывается в отчёте и
  регламенте; порог 0.5 по этим данным **не подбирается**.

Запись без найденного пика на закрытых глазах (`ec_pdr_hz = 0`) считается для H1 по полосе
8–13 Гц, как в коде. Записи, которые не читаются, перечисляются и исключаются.

## Ограничения, известные заранее

Склейка двух отдельных минутных записей — не настоящая проба в одной записи (разные отрезки
времени, возможен сдвиг электродов). Сигнал 64 канала, используются O1/O2. Это проверка
измерения, а не клинической ценности пробы.
