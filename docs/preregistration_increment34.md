# Пре-регистрация, инкремент 34: специфичность заключения у 111 здоровых взрослых (ds003775, Осло)

> Зафиксировано **до** загрузки ЭЭГ: скачаны только `participants.tsv`, описание набора и одной
> записи (`*_eeg.json`, `*_channels.tsv`); ни один сигнал не открывался.

## 1. Зачем

Инкремент 33 (Греция, пожилые 50–80 лет) подтвердил специфичность у 29 здоровых. Здесь —
другие центр (University of Oslo), прибор (BioSemi), монтаж (64 электрода 10-10, усреднённый
референт), возраст (17–71, медиана 35) и в 4 раза больше здоровых.

## 2. Данные

OpenNeuro ds003775 «SRM Resting-state EEG» (CC0): 111 здоровых взрослых, сессия t1, 4 мин покоя
с закрытыми глазами, 1024 Гц, EDF. Возраст — из `participants.tsv`. Все — здоровые (меток ЭЭГ
нет): ожидаемое заключение — «норма».

Две особенности, известные заранее и потому фиксируемые здесь:
* **64 электрода 10-10** — модель уровня записи обучена на 19 электродах 10-20 (NMT), а
  инкремент 30 показал, что модели могут выучить монтаж;
* **4 минуты** — короче типичной рутинной ЭЭГ (15–20 мин); число событий за запись меньше.

## 3. Два прогона (`scripts/run_ds003775_eval.py`, код этого коммита)

* **основной — как есть** (`as_delivered`): запись целиком, 64 электрода, как её получил бы
  развёрнутый пайплайн;
* **вторичный — 19 электродов 10-20** (`--reduce1020`): Fp1 Fp2 F7 F3 Fz F4 F8 T3(T7) C3 Cz C4
  T4(T8) T5(P7) P3 Pz P4 T6(P8) O1 O2.

Пайплайн как в харнессе рутинной ЭЭГ (без ICA, шаблонный провайдер), заключение — модель уровня
записи v2 с порогами по возрасту и пограничной зоной. Ничего не настраивается. Нечитаемые записи
и записи без оценки исключаются и публикуются числом.

## 4. Гипотеза и правило решения (`evaluation/prereg34.py`)

* **H1** — специфичность (доля без «отклонений») в основном прогоне ≥ **0.65**.
* **Правило по монтажу:** если специфичность на 19 электродах выше, чем «как есть», **более чем
  на 0.10** → заключение рутинной ЭЭГ должно считаться на стандартных 19 электродах 10-20
  (вход сводится к ним, как в мониторе новорождённых с инкремента 30); это вносится следующим
  инкрементом с проверкой регрессий на NMT. Иначе монтаж не меняется.

Описание: специфичность правил, доля пограничных, по возрастным группам, какие находки дают
«отклонения» у здоровых.

## 5. Воспроизведение

```bash
PYTHONPATH=src python scripts/run_ds003775_eval.py docs/increment34_delivered.jsonl --workers 4
PYTHONPATH=src python scripts/run_ds003775_eval.py docs/increment34_reduced.jsonl --reduce1020 --workers 4
PYTHONPATH=src python scripts/run_ds003775_eval.py --assess docs/increment34_delivered.jsonl docs/increment34_reduced.jsonl docs/increment34_assessment.json
```

## 6. Ограничения

Здоровые — по анкете и нейропсихологическим тестам, не по ЭЭГ; только покой с закрытыми глазами;
4 минуты. Специфичность здесь — у здоровых добровольцев, а не у направленных на ЭЭГ пациентов.
