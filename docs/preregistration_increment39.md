# Пре-регистрация, инкремент 39: монитор приступов на независимых данных (AUBMC, Бейрут)

> Зафиксировано до загрузки сигналов ЭЭГ: скачаны только описание набора, таблица приступов
> авторов (`Seizures_Information.xlsx`, `Seizure_times.py`) и заголовки EDF (первые 256 байт —
> время начала записи).

## 1. Зачем

Детекторы приступов проверялись только на CHB-MIT и Siena (инкременты 9–11); эти базы
исчерпаны. Текущие умолчания вне неонатального возраста — обученные модели v2 (инкремент 11:
офлайн 0.88 при 7.93 ложных/ч, монитор 0.70 при 3.30/ч). Независимого набора с разметкой
приступов на скальповой ЭЭГ другого центра не было.

## 2. Данные

AUBMC (Nasreddine; Mendeley Data 10.17632/5pc2j46cbc.1, CC BY 4.0): Американский университет
Бейрута, видео-ЭЭГ-мониторинг 2014–2015, **6 детей 4.5–9 лет** с фокальной эпилепсией
(предхирургическое обследование, противоэпилептические препараты отменены), **20 записей по
~3 ч** (~57 ч), 19–21 электрод 10-20 + ЭКГ, 500 Гц, EDF; авторы применили полосу 1/1.6–70 Гц и
режекцию 50 Гц.

**Эталон** — время начала и длительность приступов из `Seizure_times.py` авторов, переведённые
в секунды от начала каждого EDF: **30 приступов с ЭЭГ-коррелятом** (сложные парциальные и
электрографические). **Не входят в эталон и не считаются ложными тревогами** (интервалы
`ambiguous`): 4 приступа пациента 13 (записи 1–3) с пометкой авторов «нет изменений на
поверхностной ЭЭГ» и 1 приступ пациента 12, который авторы относят к записи 3, но который
лежит и в конце записи 2. Опечатка таблицы (p14_Record3: 09:50:24 вместо 21:50:24) исправлена
по коду авторов.

## 3. Прогон (`scripts/run_aubmc_eval.py`, `datasets/aubmc.py`, код этого коммита)

`evaluate_ml_test` с замороженным набором инкремента 11
(`docs/preregistration_increment11_frozen.json`, проверка SHA-256): офлайн и монитор —
обученная модель v2 в точке A (рабочие умолчания) и пороговые детекторы; правила подсчёта —
как в инкрементах 9–11 (окно до/после приступа, слияние тревог). Ничего не настраивается.

## 4. Гипотезы и правило решения (`evaluation/prereg39.py`)

Ложные тревоги — без интервалов `ambiguous` (сырые тоже публикуются).

* **H1** — чувствительность монитора (v2) ≥ **0.50**.
* **H2** — ложные тревоги монитора (v2) ≤ **5.0/ч**.
* **H3** — офлайн (v2): чувствительность ≥ **0.70** при ложных ≤ **12/ч**.
* **Правило** (для каждого пути, офлайн и монитор): если пороговый детектор чувствительнее v2
  **более чем на 0.05** и даёт **меньше** ложных тревог — умолчанием этого пути становится
  пороговый детектор; иначе v2 остаётся.

Описание: макро-чувствительность по пациентам, по пациентам, латентность.

## 5. Воспроизведение

```bash
PYTHONPATH=src python scripts/run_aubmc_eval.py --workers 3
```

## 6. Ограничения

6 пациентов (интервалы широкие); все — дети; фильтрация авторов (1/1.6–70 Гц, 50 Гц) отличается
от сырых данных обучения; часть записей нарезана так, что приступ около 2-го часа (вероятно,
отбор фрагментов авторами).
