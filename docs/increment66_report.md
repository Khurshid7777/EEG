# Инкремент 66: седация пропофолом и детектор диффузного замедления (DOSE-I) — гипотеза подтверждена

Пре-регистрация: `docs/preregistration_increment66.md` (коммит af5d5a1; дополнение до результатов — после неоценимой первой попытки). Скрипт: `scripts/run_dosei_sedation.py`.
Результаты: `docs/increment66_assess_dosei.json` (основной), `docs/increment66_assess_dosei_attempt1_not_evaluable.json` (первая попытка). Решение — D107.
Данные: DOSE-I (Zenodo 22145442, CC BY 4.0), 171 запись седации пропофолом при эндоскопии; 170 в тесте, одна отведена на проверку читателя.

## Что произошло (в порядке событий)

1. **Первая попытка** (бодрствование до первой дозы, ≥ 120 с чистого сигнала): **0 парных записей** — в наборе до пропофола ЭЭГ почти не записана (медиана 6 с чистого сигнала).
2. **Дополнение до результатов:** бодрствование — окно после возврата сознания (≥ 60 с чистого сигнала, MOAA/S ≥ 4, не раньше чем через 120 с после последней дозы). При выборе смотрелись только длительности окон,
   не срабатывания детекторов.
3. **Основной результат** (21 парная запись).

## Результат

| Показатель | Бодрствование после седации | Глубокая седация (MOAA/S ≤ 2) |
|---|---|---|
| Детектор диффузного замедления сработал | **0%** (0 из 21) | **76%** (16 из 21) |
| Медиана доли «медленных» эпох | 0.14 | 0.72 |
| Детектор вспышки-подавления сработал | 0% | 0% |

* Разность **0.762** (95% ДИ по записям 0.571–0.905), точный тест Макнемара p = 3·10⁻⁵ → **H1 подтверждена** (порог 0.30, нижняя граница > 0).
* H2 (вспышка-подавление чаще при глубокой седации): **не наблюдалась** — на этих данных вспышки-подавления нет ни в одном состоянии (пропофол при умеренной глубине, эпизоды не глубже MOAA/S 1).
  Поддержки действующему разделению по седации данные не дают, но и не противоречат ему.
* Ожидание (AWAKE 10–35%, DEEP 50–85%) оправдалось для DEEP (76%), для AWAKE результат ниже ожидаемого (0%).

## Что изменено в продукте (по пре-регистрированному правилу)

`configs/rules/neuro_rules.yaml`: цепочка `diffuse_slowing_encephalopathy` теперь действует при **неуказанных седативах**; при указанных седативах работает новая цепочка `diffuse_slowing_sedation`
с физиологией «неопределённо» и выводом «согласуется с эффектом седативных препаратов (обратимая причина); энцефалопатия не утверждается без записи вне седации».
Тесты: `test_diffuse_slowing_under_stated_sedation_is_not_called_encephalopathy`; ожидание e2e-теста обновлено (демонстрационная запись содержит седативы).

## Ограничения

* 21 пара, один центр, взрослые на эндоскопии, пропофол ± мидазолам; два фронто-височных канала при 125 Гц с условными именами F7/F8, а детектор рассчитан на 19-канальную рутинную ЭЭГ.
* Контраст «седация против бодрствования после седации»: остаточный эффект препарата мог занизить разность, а не завысить.
* Результат относится к механизму «седация → срабатывание детектора», а не к диагностической точности. Правило работает только при **указанных** седативах: если в запросе их нет, замедление по-прежнему
  читается как возможная энцефалопатия.
* Метки артефактов в наборе алгоритмические (пропуски, насыщение, малая дисперсия), не экспертные — для проверки детектора артефактов набор не годится.
