# Пре-регистрация инкремента 43: сравнение с прошлой ЭЭГ по участкам бодрствования (v2)

Зафиксировано до открытия данных ds005385. Код: `pipeline/record_summary.alert_band_shares`,
`pipeline/serial.py` (`QUANTITIES_V2`), скрипт `scripts/run_ds005385_serial.py`.

## Что было и что меняется

Инкремент 42 (D76) показал две вещи:
* пределы по долям ритмов всей записи почти не дают ложных отметок;
* открывание глаз они замечают лишь у 10%: доля альфа у здоровых между визитами меняется так
  же сильно, вероятно из-за сонливости.

**v2:** доли дельта, тета и альфа считаются только по самым бодрым эпохам — четверти 2-секундных
эпох с наибольшей долей альфа над затылком (O1/O2). Основной ритм и амплитуда — как в v1.

Вариант выбран на данных разработки инкремента 42 (ds004148 sub-01…30; `scripts/dev_serial_v2.py`,
`docs/increment43_dev.jsonl`). Сравнивались:
* квантиль отбора эпох 0, 0.5, 0.75, 0.9;
* среднее и медиана;
* отношения тета/альфа и (дельта+тета)/альфа;
* основной ритм по бодрому участку.

Результаты на разработке:

| вариант | предел по альфа | открывание глаз отмечено |
|---|---|---|
| все эпохи | в 3.1 раза | 20% |
| q = 0.75, среднее (**выбран**) | в 2.1 раза | 50% |
| q = 0.9 | — | 53% (но слишком мало эпох в 3-минутной записи) |

Отношения и медиана лучше не стали. Основной ритм по бодрому участку менее устойчив
(предел 1.56 Гц против 1.03), поэтому остаётся основной ритм всей записи. Проверочная часть
ds004148 (sub-31…60) при выборе не использовалась.

## Данные (новые, ранее не открывались — кроме заголовка одного EDF для проверки каналов)

OpenNeuro ds005385 (Wascher и соавт., Dortmund Vital Study, IfADo, Германия; CC0):
* 608 здоровых 20–70 лет, BrainAmp 64 канала, 1000 Гц;
* по 3 мин с закрытыми (EC) и открытыми (EO) глазами до (pre) и после (post) 2 часов
  когнитивных заданий;
* у 208 человек повтор примерно через 5 лет (ses-2).

Из 608 участников с ses-1 выбираются случайно (seed 43, `numpy.random.default_rng(43).permutation`
по отсортированному списку) первые 100 — для разработки пределов и следующие 100 — для проверки.
Обработка как в инкременте 42: 19 электродов 10-20, рутинный конвейер без ICA, возраст из
`participants.tsv`.

## Пары

* **Стабильность:** ses-1 EC pre против ses-1 EC post. Тот же день, 2 часа заданий между записями:
  реальная повседневная изменчивость, включая утомление.
* **Положительный контроль:** ses-1 EC pre против ses-1 EO pre.
* **Вторично (описательно):** ses-1 EC pre против ses-2 EC pre (5 лет) у участников проверочной
  части, у которых есть ses-2.

## Пределы

Для v1 и v2 — по одним и тем же 100 парам стабильности разработки: `2.576 · RMS(Δ)`. Пределы
фиксируются коммитом до прогона проверочной части.

## Гипотезы (проверочная часть, 100 человек)

* **H1 (специфичность v2):** доля людей хотя бы с одной отметкой в паре стабильности ≤ 0.15.
* **H2 (чувствительность v2):** снижение `alert_rel_alpha` сверх предела при открывании глаз
  ≥ 0.40.
* **H3 (v2 лучше v1):** открывание глаз отмечено (снижение доли альфа сверх предела) у v2 чаще,
  чем у v1, у тех же людей. Точный тест Мак-Немара, односторонний, p < 0.05.

## Правила решения

* H1 и H3 выполнены → v2 заменяет v1 в продукте; пределы v2 по ds005385 (разработка)
  записываются в `configs/serial_limits.yaml`.
  - Пометка в отчёте «отмечаются только крупные изменения» снимается, только если и H2 ≥ 0.70.
  - При H2 < 0.40 пометка усиливается указанием доли.
* H1 не выполнена для v2 → v2 не включается; v1 остаётся.
* H3 не выполнена → v1 остаётся. Пределы v1 не меняются: в продукте пределы ds004148, а пределы
  ds005385 сообщаются в отчёте.
* Пределы на проверочной части не подбираются.

## Вторично (без правил)

* **Перенос:** пределы v1 из инкремента 42 (ds004148, другая страна и возраст) на паре стабильности
  проверочной части ds005385 — доля ложных отметок.
* **5 лет:** доля людей с отметками и средние изменения основного ритма и долей.

Сбой загрузки пересчитывается один раз; нечитаемые записи перечисляются и исключаются.

## Известные ограничения

Здоровые, один центр. Положительный контроль (открывание глаз) — физиологическое, а не
патологическое изменение. Записи по 3 мин, четверть эпох — около 45 с.
