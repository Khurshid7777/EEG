# Пре-регистрация инкремента 42: серийное сравнение с прошлой ЭЭГ (пределы повседневной изменчивости)

Зафиксировано до запуска на данных. Код: `pipeline/serial.py`, скрипт `scripts/run_ds004148_serial.py`.

## Зачем

Клинический вопрос при повторной ЭЭГ — что изменилось с прошлого раза. Поле `prior_eeg_id` в
контексте есть, но не использовалось. Разница двух записей значима только тогда, когда она больше
обычной изменчивости записи у того же человека. Инкремент измеряет эту изменчивость у здоровых и
проверяет полученные пределы на других людях.

## Данные

OpenNeuro ds004148 (Wang и соавт., Юго-Западный университет, Китай): 60 здоровых молодых
добровольцев, Brain Products 64 канала, 500 Гц, три сессии. В каждой сессии 5 мин с закрытыми и
5 мин с открытыми глазами. Интервал между сессиями в README не указан. Ранее открывался только
один файл (sub-01, сессия 1, глаза закрыты) — для проверки чтения BrainVision (D74); признаки по
нему не считались.

Обработка: сокращение до 19 электродов 10-20, как в клинической записи; рутинный конвейер без ICA
(как `routine_eval.run_record`); возраст из `participants.tsv`.

## Сравниваемые величины (5)

| величина | изменение |
|---|---|
| `pdr_hz` — основной ритм | Δ, Гц (не сравнивается, если не найден хотя бы в одной записи) |
| `global_rel_delta`, `global_rel_theta`, `global_rel_alpha` | ln(B / A) |
| `robust_amplitude_uv` | ln(B / A) |

Предел для каждой величины: `z · RMS(Δ)` по парам разработки, z = 2.576 (двусторонний 1% на
величину, около 5% на все 5). Изменение «превышает повседневную изменчивость», если |Δ| > предела.
Дополнительно перечисляются детекторы, сработавшие только в одной из записей (без предела, в
гипотезы не входит).

## Разделение

* **Разработка:** sub-01…sub-30, сессия 1 против сессии 3, глаза закрыты → пределы, фиксируются в
  `configs/serial_limits.yaml`.
* **Проверка:** sub-31…sub-60, открывается только после фиксации пределов:
  - **H1 (специфичность):** сессия 1 против сессии 3, глаза закрыты: доля людей хотя бы с одним
    «превышает» ≤ 0.15 (ожидание ~0.05); приводится интервал Клоппера–Пирсона.
  - **H2 (чувствительность к настоящему изменению):** сессия 1, глаза закрыты против глаза открыты
    (положительный контроль): снижение `global_rel_alpha` сверх предела у ≥ 0.70 людей.
  - Вторично (без правила): сессия 1 против сессии 2, глаза закрыты.

## Правила решения

* H1 и H2 выполнены → пределы замораживаются, сравнение идёт в отчёт с формулировкой «превышает
  повседневную изменчивость здоровых».
* H1 не выполнена → флагов «превышает» в отчёте нет; сравнение только описательное (значения рядом).
* H2 не выполнена (H1 выполнена) → флаги остаются, но в отчёте и регламенте указано, что пределы
  нечувствительны к умеренным изменениям.
* Пределы на проверочной части не переподбираются.

Записи, которые не читаются, перечисляются и исключаются; сбой загрузки (не данных)
пересчитывается один раз, как в инкрементах 34, 35, 41.

## Известные ограничения

Молодые здоровые, один центр и прибор; у пациентов изменчивость, вероятно, больше (пределы —
нижняя граница). Интервалы сессий неизвестны. Пределы выведены для 19 электродов в усреднённом
референте.
