# Пре-регистрация инкремента 45: стадирование сна у детей (OpenNeuro ds003555)

Зафиксировано до запуска на данных. Скрипт: `scripts/run_ds003555_sleep.py`.

## Зачем

Стадирование сна проверено только у взрослых (Sleep-EDF, CAP; D32) и у детей не применяется
(`sleep.min_age_years = 18`). В сводке результатов «дети для стадирования сна» значатся среди
непроверенного. Это первая открытая детская запись сна с разметкой, доступная в среде.

## Данные

OpenNeuro ds003555 (Cserpan, Boran, Ramantani, Sarnthein; Университетская детская больница
Цюриха, CC0):
* 30 детей и подростков с эпилепсией, 0.7–17.4 года;
* первые ~3 ч ночного сна, 10-20, 1024 Гц.

Разметка — `derivatives/.../DataIntervals.tsv`: 5-минутные интервалы со стадией сна по
клинической разметке авторов (N2, N3, REM, Awake; изредка N1 и комментарии). Интервалы выбраны
авторами, а не покрывают всю запись. Ранее из набора открывались только `participants.tsv`,
описание, перечень файлов и `DataIntervals.tsv` трёх участников (для проверки формата); сигналы и
результаты стадирования не открывались.

## Метод (как в продукте)

* Вся запись читается конвейером. Стадирование — `Pipeline._sleep_staging`, т. е. рабочая модель
  с отведениями продукта (без средней линии — Fp2-C4/P4-O2 и клиническая модель D33).
* Ограничение по возрасту в проверке не применяется.
* Предсказание для интервала — стадия большинства 30-секундных эпох, целиком лежащих внутри
  интервала. N1 в предсказании засчитывается как ошибка.
* Сравниваются классы W, N2, N3, REM. Интервалы с N1 и прочими пометками исключаются.

## Метрики

* Каппа Коэна по всем интервалам. 95% ДИ — бутстреп по пациентам (2000 повторов, seed 45).
* Каппа по возрастным группам: < 6 лет и ≥ 6 лет.
* Совпадение по классам.

## Гипотеза и правило решения

* **H1:** каппа по всем интервалам ≥ 0.60.
* Стадирование включается для возрастной группы, у которой каппа ≥ 0.60 и нижняя граница ДИ ≥
  0.40:
  - проходит группа ≥ 6 лет → `min_age_years = 6`;
  - проходят обе группы → минимальный возраст выборки, 0.7 года (`min_age_years = 0.7`);
  - не проходит ни одна → остаётся 18, отрицательный результат сообщается.
* Пороги и сопоставление стадий по этим данным не подбираются.

Записи, которые не читаются или короче минимальной длительности стадирования (2 ч), перечисляются
и исключаются. Сбой загрузки пересчитывается один раз.

## Известные ограничения

* Разметка интервальная (5 мин), а не поэпоховая. Интервалы отобраны авторами, вероятно, как
  типичные.
* Дети с эпилепсией (разряды во сне), один центр.
* Межэкспертная согласованность разметки неизвестна.
