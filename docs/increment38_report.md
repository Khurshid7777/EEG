# Инкремент 38: детекторы разрядов на данных другой страны (vepiset, Пекин) — гипотезы подтверждены

Пре-регистрация: `docs/preregistration_increment38.md` (коммит d1fec72, до прогона детекторов).
Сырьё: `docs/increment38_vepiset.jsonl`; оценка — `docs/increment38_assessment.json`.
84 из 84 записей, исключений нет: 52 записи с отмеченными разрядами (3 046 событий эталона),
32 — без; 25 384 эпохи по 4 с, из них 2 502 с разрядами.

## Различение эпох (пре-регистрировано)

| | AUC (95% ДИ, бутстреп по пациентам) |
|---|---|
| **обученная модель `ied_gbm_v1`** | **0.824** (0.73–0.90) |
| эвристический детектор | 0.690 |
| разность | 0.13 (0.07–0.20) |
| модель — бодрствование (760 эпох с разрядами) | 0.718 |
| модель — сон (1 742 эпохи с разрядами) | 0.862 |

* **H1 (AUC ≥ 0.80) — подтверждена; H2 (лучше эвристики) — подтверждена.**
* Правило: AUC ≥ 0.70 → вероятность модели остаётся доводом у кандидатов (конфигурация не меняется).

## Детекторы при рабочих порогах (описание)

| | Найдено разрядов (95% ДИ) | Ложных/ч в записях без разрядов | NMT-Events (инкр. 15) |
|---|---|---|---|
| обученный, порог 0.95 (не включён) | 0.30 (0.16–0.42) | 21.3 (у 22 из 32 записей — ни одного) | 0.46 / 31.0 |
| эвристический, z = 6 (кандидаты в отчёте) | 0.64 (0.50–0.77) | 935 | 0.91 / 1 864 |

* Перенос на другую страну и прибор: различение сохранилось (0.82 против 0.72 на транзиентах
  IFCN), чувствительность при замороженном пороге ниже, чем на NMT (0.30 против 0.46), ложных
  меньше (21 против 31/ч). Критерии включения инкремента 15 (≥ 0.50 и ≤ 22.5/ч) по-прежнему не
  выполнены — модель остаётся доводом, а не детектором.
* В бодрствовании модель различает хуже (0.72), чем во сне (0.86): во сне разрядов больше и
  фон спокойнее; в бодрствовании мешают артефакты движений и мышц.
* Эвристика по умолчанию находит две трети разрядов ценой ~15 ложных в минуту — её метки в
  отчёте только «где посмотреть».

## Вывод

Первая независимая проверка детекторов разрядов на непрерывной ЭЭГ другой страны: вероятность
обученной модели переносится (AUC 0.82) и лучше эвристики; как самостоятельный детектор модель
по-прежнему не годится (0.30 разрядов при пороге 0.95).

Ограничения: разметка авторов (число разметчиков не проверялось), отметки — моменты без
длительности; «записи без разрядов» — пациенты с эпилепсией, не здоровые.
