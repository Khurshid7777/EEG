## Что изменено в продукте

* `channel_band_power`: канал-окно годно при размахе ≤ 200 мкВ; окно пригодно при ≥ 12 годных каналах; референт — по годным каналам окна; мощность канала усредняется по её годным окнам.
* `regional_series` (страница): флаг артефакта окна — менее 12 годных каналов (раньше — ≥ 2 плохих), маски плохих окон по каналам (`bad_windows_by_channel`); значения плохих каналов в окне подменяются медианой годных каналов окна (только для отображения); итоги записи (`_record_asymmetry`, `regional_summary`, статическая карта) усредняют только по годным окнам канала.
* Для редких монтажей (ПСГ, < 8 электродов) порог размаха 500 мкВ вместо 200 (как в проверках сна, инкременты 79–80; для сна 200 мкВ отбрасывает медленные волны). Это не часть пре-регистрации инкремента 82, а согласование с уже проверенными условиями; в тестах и демо учитывается.

## Ограничения

Это проверка устойчивости метода на тех же наборах, а не независимая проверка; возвращённые записи могут быть реально шумными (их доля окон помечается на странице); пределы асимметрии (инкремент 74) не пересчитывались: при необходимости пересчёт — отдельной пре-регистрацией.
