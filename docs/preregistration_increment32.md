# Пре-регистрация, инкремент 32: заключение рутинной ЭЭГ на TUH Abnormal EEG Corpus

> Зафиксировано **до** получения доступа к корпусу: ни одна запись TUAB проектом не загружалась
> и не открывалась. Запуск — после того как владелец проекта получит доступ
> (`docs/data_access_requests.md`); код этого коммита не меняется до запуска.

## 1. Что проверяется

Заключение «норма / отклонения» рутинной ЭЭГ в том виде, в котором оно работает сейчас
(`configs/impression.yaml`): модель уровня записи `record_gbm_v2` с порогами по возрасту,
вариант без возраста для записей без возраста, пограничная зона ±1.0 логита, решает модель
(`record_model_decides: true`); правила — в том же прогоне для сравнения. Ничего не
настраивается на TUAB: ни пороги, ни модель, ни фильтры.

До сих пор заключение проверено только на одном центре (NMT, Пакистан; оценочная часть авторов:
AUC 0.897, специфичность 0.789, чувствительность 0.800 — post-hoc после инкремента 25).

## 2. Данные

TUH Abnormal EEG Corpus (Temple University Hospital, США), **официальная оценочная часть**
(`edf/eval/`, в v2/v3 — 276 записей: 150 нормальных, 126 с отклонениями, метка по заключению
невролога). Обучающая часть TUAB не используется ни для чего. Возраст — из заголовка EDF
(«Age:NN»), если его нет — вариант модели без возраста. Амплитуды TUH в мкВ (масштаб 1).

Исключаются и публикуются числом: нечитаемые файлы и записи без оценки уровня записи
(не рутинные — длиннее 45 мин).

## 3. Гипотезы (`evaluation/prereg32.py`)

* **H1** — AUC оценки уровня записи ≥ **0.80** (на NMT 0.897; допускается падение при переносе).
* **H2** — сбалансированная точность заключения модели не ниже, чем у правил в том же прогоне.
* **H3** — специфичность заключения ≥ **0.65** (тот же порог, что в пре-регистрации 22).

Интервалы — точные (Клоппер–Пирсон); у одного человека в TUAB может быть несколько записей —
доля таких записей публикуется.

## 4. Правило решения (`prereg32.apply_decision`)

* **H2 ∧ H3** → `record_model_decides: true` остаётся; в сводку вносятся числа TUAB как
  внешняя проверка.
* Иначе → `record_model_decides: false`: заключение решают правила, оценка модели сохраняется
  в JSON; сводка сообщает, что модель уровня записи на другом центре не подтвердилась.
* **H1** отвергнута при H2 ∧ H3 → модель остаётся, ограничение переноса публикуется.

Вторично (без гипотез): доля пограничных заключений, доля записей без возраста, специфичность
по возрастным группам, частота находок правил у нормальных.

## 5. Воспроизведение

```bash
# после загрузки корпуса владельцем в data/tuab (структура edf/{train,eval}/{normal,abnormal}/...)
PYTHONPATH=src python scripts/run_tuab_eval.py data/tuab docs/increment32_tuab.jsonl --split eval --workers 4 --assess docs/increment32_assessment.json
```

## 6. Ограничения

* Метки TUAB — заключения неврологов одной больницы по отчётам, а не консенсус нескольких
  экспертов; часть «отклонений» может быть клинической, а не электрографической.
* Монтаж TUAB 01_tcp_ar (усреднённый референт при записи); пайплайн всегда перереферирует к
  среднему — отличия референтов не влияют, отличия фильтров и импеданса — влияют (это и
  проверяется).
* В TUAB есть электроды T1/T2 (в NMT их нет) и служебные каналы (ЭКГ, PHOTIC, ROC/LOC);
  запись анализируется **как есть** — так, как её получил бы развёрнутый пайплайн (имена
  «EEG FP1-REF» нормализуются, ЭКГ/служебные каналы исключаются, T1/T2 входят как скальповые).
  Сокращение до монтажа NMT не делается: проверяется перенос, а не лучший возможный результат.
