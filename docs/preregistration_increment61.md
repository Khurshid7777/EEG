# Пре-регистрация инкремента 61: покадровая сегментация артефактов (оценка на DREAMS Artifacts)

Зафиксировано до реализации детектора и до запуска на размеченных данных. Метод — как в инкрементах 56–60.

## Зачем

В продукте нет покадровой маски артефактов: есть флаги на всю запись и ЭКГ-событие на всю запись
(`docs/enhancement_analysis_2026-11-12.md`, пункт 1). Ложные метки разрядов сосредоточены в записях с артефактным фоном
(инкремент 38). Нужна маска «где и какой артефакт», проверенная на размеченных экспертом данных.

## Данные

DREAMS Artifacts Database (Zenodo 2650142, **CC BY-NC-ND 3.0**: некоммерческое использование, без производных работ,
с указанием авторов — University of MONS TCTS Lab (S. Devuyst, T. Dutoit) и ULB / CHU de Charleroi Sleep Laboratory
(M. Kerkhofs)). 20 отрывков по 15 минут ночной ПСГ взрослых с патологиями сна, 50 / 100 / 200 Гц, каналы Cz-A1 (или
C3-A1), Fp1-A1, O1-A1, два ЭОГ и ЭМГ; артефакты размечены экспертом по типам (интервалы «начало, длительность» в секундах).
**Набор используется только для оценки**: ни обучения, ни подбора порогов на нём, данные не распространяются; в
репозиторий попадают только агрегированные результаты.

**Что открывалось ранее:** документация набора (определения типов), названия секций разметки и число интервалов в нескольких
файлах, форматы EDF. Согласие детектора с разметкой не вычислялось; детектор ещё не реализован.

## Что запускается

Новый модуль `layer2_preprocess/artifact_segments.py`. Окна по 1 с, на канал; пороги заданы здесь и в коде совпадают:

| Тип | Правило (окно 1 с, `x` — сигнал канала в мкВ; `ref` — медиана признака по записи и каналу) |
|---|---|
| `muscle` (мышцы/движение) | P(20…min(40; 0.45·fs) Гц) / P(1…20 Гц) > 0.25 **и** P_hf > 3·ref(P_hf) |
| `high_amp` (аномально высокая амплитуда) | std(0.5–35 Гц) > max(5·ref(std); 100 мкВ) |
| `drift` (медленные колебания) | размах компоненты < 0.5 Гц в окне 4 с вокруг данной секунды > max(6·ref; 100 мкВ) |
| `pop` (скачок электрода) | max \|x[t+k] − x[t]\|, k = ⌈0.02·fs⌉, > max(15·ref; 150 мкВ) |
| `flat_sat` (плоская линия/насыщение) | ≥ 0.2 с подряд одинаковых отсчётов (в том числе на экстремуме) |
| `mains` (сетевая помеха) | P(f₀ ± 1 Гц) / P(0.5–0.45·fs) > 0.4, f₀ ∈ {50; 60} Гц, если fs > 2·f₀ + 10 |

Окно — артефактное, если сработал хотя бы один тип. Для 50 Гц: полосы мышц/сети укорачиваются или тип отключается по правилу выше.
Пороги не подбирались ни на DREAMS, ни на других реальных данных; поведение проверяется на синтетических сигналах с внесёнными
артефактами (тесты).

## Метрика

Разметка эксперта: секунда истинная, если интервал любого типа на ЭЭГ (`*E`: ondE, mvtE, highE, transE, otherE, noE, cardE,
50HzE, satE) покрывает ≥ 0.5 с секунды. Оценивается центральный канал (Cz-A1 или C3-A1), на который ссылается разметка.
Чувствительность и специфичность на секундах; 95% ДИ бутстрепом по отрывкам (2000, seed 61). Сравнение с «Automatic detection»
авторов набора (их файлы, те же секунды): разность F1. Описательно: прицельная полнота по типам (mvtE ← `muscle`+`high_amp`,
transE ← `pop`, ondE ← `drift`, highE ← `high_amp`), доля секунд с разметкой артефакта в отрывках.

## Гипотезы и правила решения

* **H1:** чувствительность ≥ 0.60 **и** специфичность ≥ 0.80.
  * «Подтверждено» → маска (`artifact_segments`) добавляется в результат анализа как довод; на заключения не влияет.
  * «Ограниченно» (чувствительность ≥ 0.40 и специфичность ≥ 0.70) → то же, с оговоркой в описании модуля.
  * Иначе «не выдержало» → модуль остаётся в репозитории выключенным; в продукт не подключается.
* **H2:** F1 детектора не ниже F1 алгоритма авторов набора минус 0.05.
* Влияние маски на разряды (ложные/ч) проверяется отдельным пре-регистрированным парным тестом (инкремент 62), не здесь.

**Ожидание.** Чувствительность 0.45–0.65, специфичность 0.75–0.90; на отрывках 50 Гц хуже (нет полосы мышц). Тип `drift`
может плохо совпадать с «slow ondulations» эксперта (определение в документе набора расплывчато). Не уверен, что H1
подтвердится в полном виде.

## Ограничения

* Ночная ПСГ взрослых с тремя ЭЭГ-каналами и неполной сменой стадий, не рутинная ЭЭГ с 19 каналами.
* Разметка одним экспертом; типы пересекаются; в наборе нет насыщений, одна сетевая помеха.
* Доля секунд с артефактами в отрывках может быть высокой, что влияет на специфичность; приводится описательно.
