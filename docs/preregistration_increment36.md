# Пре-регистрация, инкремент 36: модель уровня записи не отменяет вспышку-подавление (проверка регрессий на NMT)

> Зафиксировано до прогона. Это **проверка регрессий**, а не новая валидация: оценочная часть
> NMT использовалась в инкрементах 22–26, а I-CARE, на котором найдена проблема, — в инкременте 35.

## 1. Что меняется (`configs/impression.yaml`, `record_model_cannot_clear`)

Правило решения инкремента 35 сработало (D68): модель уровня записи отменяла верные находки
правил в коме, 201 раз — вспышку-подавление. Изменение: если правила нашли
**вспышку-подавление** (`burst_suppression`), заключение — «отклонения», даже когда оценка
модели ниже порога или в пограничной зоне; в тексте заключения сказано, что оценка, обученная
на рутинной ЭЭГ бодрствования, эту находку не отменяет.

Набор сужен по сравнению с формулировкой правила в пре-регистрации 35 («подавление /
вспышка-подавление / периодические разряды»), и это решение принято **по уже виденным
данным**: периодические разряды (ЛПР/БИПР) правила находят у 8 из 140 здоровых взрослых
(ds003775, ds004504), вспышку-подавление — ни у одного. Пост-хок на I-CARE: чувствительность
0.307 → 0.639 (с периодическими разрядами — 0.685 ценой ложных находок у здоровых пожилых).
Отдельного детектора «подавления» без вспышек в правилах нет.

## 2. Проверка (`evaluation/prereg36.py`)

Оценочная часть NMT (`neurolens routine eval`, текущая конфигурация с запретом), 185 записей
(95 норм, 90 отклонений). Сравниваются заключение с запретом (`impression_abnormal`) и
решение одной модели (`model_abnormal`) в тех же прогонах.

**Правило:** запрет сохраняется, если специфичность с ним ниже, чем у модели одной, **не
более чем на 0.02** (≤ 2 из 95 норм); иначе запрет снимается. Ожидание (по результатам
инкремента 22, до прогона): у норм NMT вспышки-подавления не было ни разу — потеря 0.

Описание: сколько записей затронул запрет, чувствительность с ним и без.

## 3. Воспроизведение

```bash
PYTHONPATH=src python -m neurolens.cli routine eval --workers 4 --out docs/increment36_nmt_eval.json
PYTHONPATH=src python -c "import json; from neurolens.evaluation.prereg36 import assess; \
  print(json.dumps(assess(json.load(open('docs/increment36_nmt_eval.json'))['records']), indent=1))"
```

## 4. Ограничения

Пользу запрета (0.31 → 0.64) показывают только данные, по которым он выбран; независимой
проверки на записях реанимации нет. Даже с запретом чувствительность в коме ниже 0.80:
заключение рутинной ЭЭГ не предназначено для реанимации.
