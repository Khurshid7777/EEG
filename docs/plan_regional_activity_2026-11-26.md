# План: региональная функциональная карта коры + визуализация (новое направление)

Статус: **фазы A и B1–B2 (физиологические контроли) выполнены в инкременте 73 (D113); дальше нормативы асимметрии (инкремент 74) и визуализация.**

## 0. Цель и честные границы

**Цель.** По автоматически проанализированной ЭЭГ показывать, **над какими областями коры** (доли, полушария) наблюдается активность и какая именно: фоновый ритм, замедление, разряды, ритмика, веретена и т. п.; и показывать это **одновременно с диагностическим процессом** (детекторы → правила → заключение), чтобы врач видел «что найдено» и «где» на одном экране.

**Границы, которые сохраняем.**
* 19 электродов 10-20 дают скальповое региональное картирование (доли и полушарие), **а не** точную локализацию источников. Формулировки: «над левой височной областью…», а не «источник в гиппокампе».
* «Какая часть коры функционирует» — это интерпретация ритмов по литературе (например, затылочный альфа-ритм при закрытых глазах = покой зрительной коры), а не прямое измерение функции. Каждая такая связка идёт с источником (сверка цитат заблокирована: eutils закрыт) и помечена как «ориентировочная».
* Верификация — на открытых данных с известной локализацией и на физиологических положительных контролях; без неё карта в продукт не включается (как с детекторами).

## 1. Фаза A — региональный слой признаков (код, без новых данных)

1. Схема областей 10-20: Fp/F (лобные), C (центральные), T (височные), P (теменные), O (затылочные) × левое/правое/срединное.
2. Для окна и для записи: мощность по полосам (дельта…бета) по областям; индекс межполушарной асимметрии по гомологичным парам (F3–F4, C3–C4, T3–T4, P3–P4, O1–O2, F7–F8, T5–T6); частота доминирующего ритма затылочных областей (PDR), её симметрия.
3. Привязка существующих событий к областям: у детекторов уже есть каналы события → плотность событий по областям (спайки, острые волны, замедление, ритмика, вспышка-подавление, приступ).
4. Региональные находки правил: фокальное замедление (область, сторона), латерализованные разряды, затылочное замедление — с указанием сторон и степени уверенности. Правила `neuro_rules.yaml` расширяются осторожно (гипотезы «уверенно/вероятно/недостаточно данных»).
5. Тесты на синтетических сигналах с известной областью (известная локализация → известная карта).

## 2. Фаза B — пре-регистрированная проверка (открытые данные)

Гипотезы фиксируются до открытия записей (по образцу инкремента 70).

| Проверка | Данные | Что проверяем | Критерий (черновик) |
|---|---|---|---|
| B1. Физиологический контроль: затылочный максимум альфа | ds003775 (111), eegmat (36), ds004504 контроли (29) | область с максимумом альфа при закрытых глазах = затылочная | ≥ 90% записей |
| B2. Контроль: эффект счёта | eegmat (фон `_1` против счёта `_2`) | рост лобной тета и спад альфа при счёте | направление эффекта у ≥ 70% испытуемых, ДИ по испытуемым |
| B3. Латерализация приступов | CHB-MIT, Siena (метки начала, сторона/доля очага в метаданных Siena) | сторона и доля начала приступа по карте против клинической | согласие стороны ≥ 70%, доли — отдельно, без порога по умолчанию |
| B4. Региональное замедление при деменции | ds004504 (Альцгеймер и ЛТД против контролей) | задние/височные области: рост дельта/тета, спад альфа | направление и размер эффекта по областям, Холм-коррекция |
| B5. Веретена сна | CAP, Sleep-EDF (где есть центральные каналы) | веретена центрально-лобные в N2 | описательно |
| B6. Устойчивость к монтажу | те же данные с 19 против 64 электродов (ds003775) | карта не зависит от числа электродов | согласие областей максимума |

Негативные результаты публикуются. Порогов по данным проверки не подбираем.

## 3. Фаза C — визуализация (две одновременные линии)

Основной экран (интерактивная HTML-страница; а также PNG/PDF для отчёта), синхронизированный по времени:
* **Линия 1 — процесс диагностики:** временная ось записи с детекторами, стадиями сна (если есть), артефактами, рисками (приступ/кандидат), ссылкой на сработавшие правила.
* **Линия 2 — региональная карта:** скальповая топокарта и схема долей для выбранного окна (ползунок или клик на событии): мощность по полосам, асимметрия, события по областям, подпись «над левой височной…».
* Сравнение «два состояния» (фон против задачи, ранее/позже, левое против правого) — по запросу.
* Подписи с оговорками, видимыми на самой карте («скальповое картирование, 19 электродов»).

## 4. Фаза D — интеграция и документация

Подключение к `pipeline` (поле `regional_summary` в JSON), раздел в PDF-отчёте, тесты, карточка метода, `DECISIONS.md`, ограничения. Опционально — оценка источников (sLORETA/шаблонная голова): только при ≥ 32 электродах и после установки MNE; для 19 электродов не заявляется.

## 5. Порядок работ и ворота

1. Согласовать вопросы ниже → пре-регистрация 73 (фаза B) **до** кода фазы A.
2. Фаза A (код + синтетические тесты).
3. Фаза B (прогон по данным; отчёт, в т. ч. негативный).
4. Фаза C (визуализация) — только для областей, прошедших B.
5. Фаза D.

Ожидаемые риски: артефакты (глазные в лобных, мышечные в височных) создают ложные «активности» — используем сегментацию артефактов продукта (v1 не прошла тест, в пайплайн не подключена, поэтому выводы по лобным/височным областям формулируем осторожнее); зависимость карты от референта (усреднённый, ушной).

3. Формат вывода: интерактивная страница, PDF-отчёт или оба?
4. С чего начинать проверку: физиологические контроли (затылочная альфа, эффект счёта), эпилептические очаги (CHB-MIT, Siena) или оба?
