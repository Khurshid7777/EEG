# Инкремент 29 (разработка): офлайн-оценка фона новорождённых

> **Не независимая проверка.** Числа ниже — на наборе Cork, который уже был тестом в
> инкременте 28 (там офлайн-фон шёл вторичным описанием). Изменения выбраны по стандарту аЭЭГ
> и ACNS, а не подбором порогов, но оценка на тех же данных оптимистична. Сырьё:
> `docs/increment29_cork_offline.json` (`scripts/cork_grades_eval.py --offline-only`).

## Что было сломано (инкремент 28, §2а)

«Не по возрасту» — во всех 169 часах, категория аЭЭГ «плоская» — в 38 из 104 часов нормального
фона. Причины:

1. **Нижний край аЭЭГ** считался как 10-й перцентиль выпрямленных отсчётов; туда попадают
   переходы через ноль → ≈ 0.5 мкВ в любой записи, фон никогда не «непрерывный».
2. аЭЭГ — по одному каналу усреднённого референта, а не по межполушарному биполярному
   отведению (стандарт аЭЭГ: C3–C4 / P3–P4).
3. Непрерывность и IBI — старым методом по огибающей одного канала (тот самый, что в
   инкременте 17 признан негодным для вспышки-подавления).
4. Отсутствие цикла сон-бодрствование считалось отклонением в часовой записи.

## Что изменено

* Края аЭЭГ — 10-й/90-й перцентили размаха (peak-to-peak) сигнала 2–15 Гц в 1-с сегментах
  (масштаб краёв Hellström-Westas), отведение C3–C4 (иначе P3–P4, T3–T4, F3–F4).
* Непрерывность/IBI новорождённых — по маске подавления ACNS (< 10 мкВ размах на медианном
  канале) по всем каналам.
* Цикл сон-бодрствование оценивается только в записях ≥ 3 ч; иначе в отчёте «SWC не
  оценивается (< 3 ч)».

Монитор не затронут (он использует только ACNS-детектор вспышки-подавления): результаты
инкремента 28 по тревогам остаются в силе.

## Результат на Cork (169 ч, повторное использование)

| Степень | Часов | Категория аЭЭГ | «Не по возрасту» было → стало |
|---|---|---|---|
| 1 норма/лёгкие | 104 | CNV 104 | 104 → **2** |
| 2 умеренные | 31 | CNV 31 | 31 → 9 |
| 3 тяжёлые | 22 | CNV 12, DNV 4, BS 4, CLV 2 | 22 → 12 |
| 4 неактивная | 12 | CLV 5, CNV 5, FT 1, DNV 1 | 12 → 11 |

Специфичность «не по возрасту» на степени 1 — 0.98, доля отмеченных часов степени 3–4 — 0.68.
Остающаяся слабость: 5 из 12 «неактивных» часов классифицированы по аЭЭГ как непрерывные
(вероятно, артефакт — ЭКГ, сетевая наводка — поднимает края при подавленной ЭЭГ); отметку
«не по возрасту» они всё равно получают по непрерывности/IBI. Порогов по этим данным не
подбирали; независимой проверки офлайн-фона пока нет.
