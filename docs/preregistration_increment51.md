# Пре-регистрация инкремента 51: многоцентровой стадировщик для монтажа AASM, тест на HMC

Зафиксировано до запуска на тестовых данных. Разработка — `scripts/dev_aasm_stager_v3.py`, проверка —
`scripts/run_hmc_sleep.py`.

## Зачем

Инкремент 50 (D92): стадировщик v2, обученный на одном центре (ds007181), на EESM19 дал каппу 0.559,
на BOAS — 0.526. Гипотеза: модели не хватает разнообразия центров и оборудования. v3 обучен на трёх
центрах сразу.

## Разработка

Ночи: ds007181 — 59, BOAS (ds005555) — 128, EESM19 (ds005185) — 78 (из 80; sub-011 ses-004 и
sub-013 ses-001 — усечённые файлы `.fdt`, исключены, как в инкременте 50). BOAS и EESM19 ранее
служили тестами (инкременты 49–50), теперь они — обучающие данные; повторно как тест не используются.
Признаки строятся теми же производными продукта (F4-C4, C4-O2, горизонтальная ЭОГ).

Проверка с исключением одного центра (`docs/increment51_dev_loco.json`):

| Отложенный центр | Каппа | Для сравнения (одноцентровая v2) |
|---|---|---|
| ds007181 | 0.537 | CV внутри центра 0.622 |
| BOAS | 0.543 | 0.526 |
| EESM19 | 0.567 | 0.559 |

Слабые классы — N1 (F1 0.32–0.41) и N3 (F1 0.20–0.55). Прирост от трёх центров на новом центре
небольшой; ожидаемая каппа на незнакомом центре — около 0.55, то есть **ниже порога H1**. Тест всё
равно проводится: порог не снижается, модель не подбирается.

Финальная модель обучена на всех 265 ночах: `configs/models/sleep_stager_aasm_v3.json`, SHA-256
`8a7a55e0389bd1e9d68787e9915babc5c05f3d39d6042f76dac42c730b8b66a4`.

## Тест: PhysioNet HMC Sleep Staging 1.1, ранее не использовался

Haaglanden Medisch Centrum (Гаага, Нидерланды): 151 клиническая ПСГ (направления в лабораторию сна,
возраст 53.9 ± 15.4), разметка по AASM. Каналы EEG F4-M1, C4-M1, O2-M1, C3-M2, EOG E1-M2, E2-M2,
ЭМГ, ЭКГ. Эпоха разметки — строка файла `_sleepscoring.txt` с длительностью 30 с; индекс эпохи
`round(onset / 30)`. Строки «Lights off/on» и не-стадийные исключаются.

Ранее из набора открывались: `RECORDS`, перечень файлов, заголовок одного EDF (имена каналов),
первые строки `SN001_sleepscoring.txt`, `Subjects_info_aggregated.txt`, `LICENSE`. Сигналы и
полные разметки не открывались.

* Путь продукта: `Pipeline._sleep_staging` с `aasm_model` = v3 (производные F4-C4 = (F4-M1) − (C4-M1),
  C4-O2 = (C4-M1) − (O2-M1), ЭОГ E1-E2).
* **Основная метрика:** каппа (5 классов) по всем эпохам всех записей; 95% ДИ — бутстреп по записям
  (2000, seed 51).
* Справочно: точность, macro-F1, F1 по стадиям, медиана каппы по записям, матрица ошибок.

## Гипотеза и правило решения

* **H1:** каппа ≥ 0.60 и нижняя граница ДИ ≥ 0.50.
* Выполнено → `sleep.aasm_model` = v3 в `configs/sleep.yaml`: монтаж AASM стадируется.
* Не выполнено → остаётся выключенным; результат сообщается, ограничение остаётся в R1 / карточке.
* Ничего на тесте не подбирается. Записи, которые не читаются или не стадируются, перечисляются и
  исключаются; сбой загрузки повторяется один раз.

## Известные ограничения

* HMC — клиническая когорта (апноэ, бессонница и др.), старше обучающих.
* Разметка одним экспертом на запись; межэкспертное согласие на HMC неизвестно.
