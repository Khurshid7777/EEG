# Протокол «теневого» пилота: NeuroLens в тихом режиме на потоке рутинных ЭЭГ (черновик)

Черновик для обсуждения с клиникой-партнёром и этическим комитетом; не является разрешением на исследование. Требуется утверждение комитетом по этике и договор об обработке данных.

## 1. Цель

Измерить, как автоматический анализ расходится с окончательными заключениями врачей **до любого показа системы врачу**: ошибки «норма/отклонение», пропущенные клинически значимые разряды, нагрузка ложных пометок на запись, время обработки. Результат определяет, можно ли переходить к режимам «второй читатель» и «помощник первого читателя».

## 2. Дизайн

* Проспективный, одноцентровый, наблюдательный; система работает **локально** на копии записи, результат пишется в закрытое хранилище, врачи его не видят.
* Включение: подряд идущие рутинные ЭЭГ взрослых и детей ≥ 6 лет (отдельно — дети младше; новорождённые и ИОРИТ — отдельные когорты). Исключение: отказ пациента, записи < 10 мин, монтаж вне 10-20.
* Данные: запись (EDF), возраст, пол, клинический вопрос, **окончательное подписанное заключение** (источник истины — заключение; для спорных случаев — пересмотр двумя независимыми нейрофизиологами вслепую относительно результатов системы).
* Размер: ≥ 300 последовательных записей (оценка специфичности ±5% при 0.80, чувствительности ±7% при ≥ 100 патологических записей); окончательный размер — после обсуждения со статистиком.

## 3. Конечные точки (заданы до начала)

| Точка | Определение | Критерий успеха для перехода к режиму «второй читатель» |
|---|---|---|
| Первичная | расхождение «норма/отклонение» системы с заключением: специфичность на нормальных заключениях и чувствительность на патологических (по уровню записи) | специфичность ≥ 0.80 (нижняя граница ДИ ≥ 0.75); чувствительность ≥ 0.80 (нижняя граница ДИ ≥ 0.70) — пороги подлежат утверждению клиницистами |
| Вторичные | доля записей с критической пометкой; число событий «кандидат» на час; доля записей, где система нашла эпилептиформные разряды при заключении «норма» (потенциально пропущенные — на пересмотр) и где врач нашёл разряды при «норме» системы; время обработки | описательно, без порогов; пропущенные случаи пересматриваются |
| Безопасность | любые случаи, когда система выдала бы критическую находку при заключении без приступов, и наоборот; сбои (не обработано), ошибки формата | все случаи разбираются, отчёт по безопасности |

## 4. Меры безопасности

* Система не меняет клинический путь пациента; результаты скрыты до закрытия исследования (или показываются только по отдельному решению комитета).
* Обезличивание (`api/deid`), журнал аудита, локальное хранение; без передачи вне клиники.
* Промежуточная проверка безопасности после первых 50 записей; остановка при системных ошибках.

## 5. Анализ

Матрицы ошибок по возрастным группам и приборам; ДИ Клоппера–Пирсона; разбор всех расхождений врачом (причины: нормальный вариант, дремота, артефакт, пропуск врача, ошибка системы); сравнение с результатами открытых наборов (специфичность 0.96–1.00 на здоровых; NMT 0.72–0.79); публикация отчёта, включая отрицательные результаты.

## 6. Следующие ступени

«Второй читатель» (после тихого режима) → «помощник первого читателя» (после клинического исследования и юзабилити с клиницистами по `docs/usability_regional_view.md`).

## 7. Ограничения

Одноцентровое; истина — заключение врача (несовершенный эталон: согласие экспертов по разрядам невысоко, `docs/increment16_report.md`); нужны ресурсы клиники для пересмотра спорных записей.
