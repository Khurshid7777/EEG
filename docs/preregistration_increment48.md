# Пре-регистрация инкремента 48: устойчивость монитора приступов к потере электродов

Зафиксировано до прогона. Повторное использование AUBMC (инкременты 39 и 47) — как вторичный
анализ устойчивости: модель и точка заморожены, порогов не подбирается.

## Вопрос

В длительном мониторинге электроды отходят постоянно. Монитор требует не менее 4 ЭЭГ-каналов, но
не проверялось, как падает чувствительность и растут ложные тревоги, когда часть из 19 каналов
пропала.

## Метод

* Данные: потоковые признаки монитора для 20 записей AUBMC (`data/aubmc/stream`, кэш
  инкремента 39). Замороженная `ictal_gbm_realtime_v2` (SHA-256 из
  `preregistration_increment11_frozen.json`), точка 0.7 × 5, причинное сглаживание, правила
  оценки приступов как в инкременте 39.
* Потеря электродов моделируется удалением столбцов каналов из матриц признаков эпох
  (`epoch_rms`, `epoch_band_conc`, `epoch_domfreq`, `epoch_relpow`). Это не моделирует плоский
  или шумящий электрод — только его исчезновение.
* Число потерянных каналов k = 0, 1, 3, 6, 9, 12; на каждое k — 20 случайных наборов
  (зерно 0..19), общий для всех записей (одни и те же каналы пропали во всей записи).
* Метрики: чувствительность по приступам (без «неоднозначных», как в инкременте 39) и ложные
  тревоги в час; среднее по наборам, диапазон min–max.

## Гипотезы и правило решения

* **H1:** при k = 1 чувствительность не ниже, чем при k = 0, более чем на 0.05 (абс.) и ложные
  тревоги не выше 1.5 × k=0 — в среднем по наборам.
* **H2 (описательная):** наибольшее k, при котором среднее по наборам удовлетворяет условию H1.
* Решение:
  * H1 выполнена → в документации указывается измеренная граница (k из H2);
  * H1 не выполнена → в сводке монитора при потере каналов (число ЭЭГ-каналов меньше числа,
    на котором обучена модель, на заданную долю) предупреждение, как для неполного набора
    электродов; порог в предупреждении — по измерению, не подбирается на тесте.
* Монитор, модель и пороги не меняются.
