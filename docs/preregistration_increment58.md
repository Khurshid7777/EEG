# Пре-регистрация инкремента 58: заключение «норма / отклонения» у здоровых младенцев (OpenNeuro ds004577)

Зафиксировано до открытия сигналов (кроме одной проверочной записи, см. ниже). Метод тот же, что в инкрементах 56–57.

## Зачем

В инкременте 56 специфичность в возрасте до 2 лет была самой низкой среди групп (0.670, ДИ 0.564–0.765, n = 91), и
это тот же центр, что и разработка. Нужен независимый центр с нормальными младенцами, чтобы понять, применимо ли
заключение к первому году жизни и что сказать врачу.

## Данные

OpenNeuro **ds004577** (CC0): покоящаяся ЭЭГ 103 здоровых младенцев первого года жизни (Нейробиологический институт,
UNAM, Мексика), 130 записей; 21 канал 10-10 (Fp1…O2, F7–T6, Fz/Cz/Pz, Pg1/Pg2), 200 Гц, около 12 минут,
открытый доступ. Возраст — `age_acq_time` из `*_scans.tsv` (годы): первая сессия каждого ребёнка, от 0.022 до 1.05
года, медиана 0.283 (≈ 3.4 мес.). Тест — **одна запись на ребёнка (сессия 1)**, 102 записи: `sub-NORB00001` исключена,
потому что на ней проверяются читатель и единицы до пре-регистрации результатов. Повторные сессии (27 записей)
не используются, чтобы дети не считались дважды.

**Что открывалось ранее:** список файлов, возраст всех записей, `README`, `dataset_description.json`, метаданные
записи `sub-NORB00001` (каналы, события, частота дискретизации). Сигналы тестовых 102 записей не открывались.

## Что запускается

Текущая рабочая конфигурация без изменений (`run_record` с `scale=1.0`, EDF в мкВ, возраст из `scans.tsv`).
Метка «норма» у всех записей; патологических записей в наборе нет, **чувствительность не проверяется**.

## Метрика

Специфичность = доля записей, для которых итоговое заключение не «отклонения»; точный 95% ДИ Клоппера–Пирсона.
Описательно: по возрасту (< 3 мес., 3–6 мес., ≥ 6 мес.), только правила, только модель, доля пограничных, какие
детекторы чаще всего срабатывают.

## Гипотеза и правило решения

* **H1:** специфичность ≥ 0.72 (цель рабочей точки).
  * ≥ 0.72 → изменений нет; число и ДИ вносятся в отчёт о качестве как «независимый центр, первый год жизни».
  * 0.50–0.72 → заключение остаётся, но для возраста < 1 года в текст отчёта добавляется оговорка с числом этого
    теста («у здоровых младенцев ложные "отклонения" в X%: заключение — только повод для просмотра»).
  * < 0.50 → для возраста < 1 года заключение «норма / отклонения» считается непроверенным: текст сообщает об этом,
    итог решает врач (модель записи для этого возраста не применяется как решающая).
* Порогов и модели по этим данным не подбирать.

**Ожидание.** 0.40–0.65: в NMT возраст до 2 лет дал 0.67 при разработке на тех же данных; первый год жизни — сон,
веретёна, возрастные медленные ритмы, обучающих данных очень мало. Выше 0.72 маловероятно.

**Исключения.** Запись, которая не читается, исключается и перечисляется; сбой загрузки повторяется один раз.

## Ограничения

* «Здоровые» означает отбор авторов (нормальное развитие), а не клиническое заключение по каждой записи.
* Один центр, один прибор; чувствительность в этом возрасте не проверена.
* Записи включают сон и бодрствование без разметки состояний.
