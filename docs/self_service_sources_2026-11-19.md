## 3. Знания, которые можно получить самостоятельно

* Статьи в открытом доступе (PMC, arXiv) — для сверки цитат правил, где адрес известен. Закрыты основные журналы (LWW, Springer, Nature): оригиналы ACNS 2021 (J Clin Neurophysiol) читать нельзя.
* Таблицы с клиническими данными без сигналов (Dryad: например «Criteria for defining interictal epileptiform discharges in EEG», «Generalized polyspike train…»): как источник связей «паттерн — причина».
* Hugging Face: наборы ЭЭГ с картами (EEGDash — зеркало OpenNeuro, seizure-изображения и др.); данные производные и без клинической разметки уровня заключения — как источник не годятся.

## 4. Что можно делать совсем без внешних данных

* Физиологические симуляторы для проверки логики правил (трифазные волны, вспышка-подавление, седация): тесты поведения, не клинической точности.
* Повторный анализ уже полученных строк результатов (но файлы вне репозитория пропадают при смене контейнера — их нужно сохранять в `docs/`).
* Самосогласованность: сверка текстов отчёта с кодом (например, аудит правил), тесты на «недостижимые правила».

## 5. Что нельзя взять самим

NMT-4K (запрос доступа), TUH (форма), BDSP (аккредитация, ключи AWS), NCH Sleep DataBank и CPS (аккредитация PhysioNet), Kaggle HMS (ключ в окружении, правила соревнования), NSRR и ISRUC (домены закрыты), MASS (запрос), оставшиеся 413 пациентов I-CARE.

## Предлагаемый порядок «самостоятельных» работ

1. Закончить DOSE-I (идёт); затем **ds004541** как вторая проверка эффекта наркоза.
2. **ds006386 PhysioMotion_Artifact**: сначала прочитать README и формат меток; если метки временные, пре-регистрировать вторую версию сегментации артефактов (инкремент 61).
3. **CinC 2018, ≈ 700 нетронутых записей**: основа для пре-регистрированного улучшения стадии N1 (разрыв с экспертами 0.14 каппы) с честным независимым тестом.
4. Открыть домен `eutils.ncbi.nlm.nih.gov` (ваше решение) — тогда сверка цитат правил делается самостоятельно.
