# Пре-регистрация инкремента 84: проверка правдоподобия подписей электродов по топографии альфа-ритма

Зафиксировано до кода проверки и до расчёта. Идея эксперта-нейрофизиолога (`docs/expert_neurophysiologist_review_2026-11-28.md`, п. 1): в рутинной ЭЭГ часто путают или неверно подписывают каналы; у бодрствующего с закрытыми глазами альфа-ритм максимален сзади (подтверждено в инкременте 73: 92–96%). Если максимум альфа оказался впереди и сзади его нет — вероятна путаница подписей, и «очаги» и «асимметрия» нельзя читать буквально.

## Правило (фиксировано здесь)

`montage_sanity(signal, channels, fs)`: общий средний референт, устойчивая отбраковка окон (инкремент 82), относительная альфа 8–12 Гц по каналам; **подозрение на путаницу подписей**, если одновременно: (а) среди **трёх** каналов с наибольшей относительной альфой нет ни одного затылочного или теменного (O1, O2, P3, P4, Pz); (б) средняя относительная альфа затылочных+теменных каналов **ниже** средней по лобным+височным. Иначе — «правдоподобно». Для записей с менее чем 8 пригодными электродами проверка не выполняется («недостаточно данных»). Правило применимо только к записи бодрствования с закрытыми глазами (на странице и в отчёте это указывается); для сна, наркоза, комы оно не определено.

## Данные и перестановки

Здоровые записи с закрытыми глазами: ds003775 (n = 111) и ds004504 контроли (n = 29). Записи **без изменений** дают долю ложных срабатываний. Искусственные перестановки имён каналов (сигнал не меняется, меняются подписи):
* **S1:** (O1, O2) ↔ (Fp1, Fp2);
* **S2:** (O1, O2) ↔ (F7, F8);
* **S3:** (Pz, P3, P4) ↔ (Fz, F3, F4);
* **S4:** (T5, T6, O1, O2) ↔ (F7, F8, Fp1, Fp2) (крупная путаница);
* **S5 (контроль, ожидаемо не обнаруживается):** O1 ↔ O2 (левое-правое при той же области).

## Критерии

* **C1 (ложные срабатывания):** доля подозрений на записях без изменений ≤ **0.08** в каждом из двух наборов.
* **C2 (чувствительность):** обнаружение перестановок S1, S2, S4 ≥ **0.85** (по записям обоих наборов вместе); S3 — **описательно** (теменные↔лобные, ожидаем 0.4–0.8: два из трёх каналов остаются «сзади» на других позициях).
* **C3 (S5):** подтверждение, что левое-правое не обнаруживается (чувствительность ≤ 0.10) — честная граница метода, не критерий успеха.
**Решение:** если C1 и C2 выполнены — `montage_sanity` подключается к конвейеру как **предупреждение** («подписи каналов выглядят неправдоподобно для бодрствования с закрытыми глазами; проверьте монтаж»), без блокировки заключения; иначе — в продукт не подключается, результат публикуется.

## Ожидание

C1: ложных 3–8% (92–96% записей имеют максимум альфа сзади, а правило строже — три канала без заднего). C2: S1, S4 ≈ 0.95–1.00; S2 ≈ 0.85–0.97; S3 ≈ 0.4–0.8. Вероятность пройти C1 и C2 ≈ 65%.

## Ограничения

Здоровые молодые и пожилые добровольцы, записи с закрытыми глазами; клинические записи с замедлением ЗДР, открытыми глазами или дремотой дадут больше ложных срабатываний (измеряется отдельно в пилоте); искусственные перестановки не отражают реальный спектр ошибок; левое-правое не определяется.
