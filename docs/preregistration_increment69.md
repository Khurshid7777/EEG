# Пре-регистрация инкремента 69: новые признаки стадии N1 (`aasm_v5`)

Зафиксировано до построения признаков на данных. Метод — как в инкрементах 51–56. Продолжение инкремента 68 (сдвиг порога N1 не помог, `docs/increment68_report.md`).

## Гипотеза

N1 определяется по AASM тремя признаками, которых у `aasm_v4` нет в явном виде: **замедление и исчезновение затылочного альфа-ритма** (переход бодрствование → N1), **медленные движения глаз** и
**вертекс-волны** (острые лобно-центральные транзиенты 2–8 Гц); дополнительно — отсутствие мышечного тонуса. v4 видит только мощность в полосах, энтропию и признаки Hjorth на 30-секундных эпохах.

## Новые признаки (13; 30-секундная эпоха, 100 Гц, производные продукта F4-C4 / C4-O2 / ЭОГ)

Пороги заданы здесь и не подбираются на данных:

| Признак | Определение |
|---|---|
| `po_alpha_dom_frac` | доля 2-секундных окон C4-O2, где мощность 8–12 Гц больше мощности 4–8 Гц и 12–16 Гц |
| `po_alpha_rel_max` | максимум по окнам относительной мощности 8–12 Гц (к 0.5–30 Гц) |
| `po_alpha_peak_freq` | медиана по окнам частоты максимума спектра в 6–13 Гц |
| `po_alpha_fluct` | стандартное отклонение по окнам относительной мощности 8–12 Гц |
| `fc_vx_count` | число пиков в F4-C4 после полосы 1–8 Гц (Баттерворт 2-го порядка, нулевая фаза) с заметностью ≥ 8 × робастной σ (1.4826 × MAD) и расстоянием ≥ 1 с |
| `fc_vx_logamp` | log(наибольшая заметность пика в эпохе / робастная σ) |
| `fc_crest` | max\|x\| / RMS после полосы 1–8 Гц |
| `fc_log_gamma`, `fc_gamma_beta` | log мощности 30–45 Гц; log отношения мощности 30–45 Гц к 16–30 Гц (мышечная активность) |
| `fc_delta_fluct` | стандартное отклонение по 2-секундным окнам относительной мощности 0.5–4 Гц |
| `eog_log_sem`, `eog_sem_rel`, `eog_sem_rapid` | медленные движения глаз: log мощности 0.2–0.7 Гц (Уэлч, окно 10 с); её доля в 0.1–8 Гц; log отношения к мощности 2–8 Гц |

Остальная схема признаков (поэпоховая робастная z-нормировка по ночи, контекст ±2 эпохи, абсолютные признаки `name@abs` v4) не меняется.

## Данные разработки и проверка (leave-one-centre-out)

Четыре центра разработки v4: OpenNeuro ds007181 (Чунцин), BOAS ds005555 (Сарагоса), EESM19 ds005185 (Орхус), PhysioNet HMC (Гаага). Для каждой ночи строятся **оба набора признаков** (прежние + новые) одним проходом,
чтобы сравнение было парным на одних и тех же ночах и фолдах. Дизайн B — признаки v4; дизайн C — B + 13 новых. Обучение — та же градиентная модель (`fit_stager`), без перенастройки гиперпараметров.

**Критерий принятия кандидата `aasm_v5` на этапе разработки (все условия):**
1. средняя по четырём фолдам каппа дизайна C выше B не менее чем на **+0.008**;
2. F1 стадии N1 у C выше, чем у B, **не менее чем в 3 из 4** центров;
3. ни у одного центра каппа C не ниже B более чем на 0.01.
Если не выполнено — инкремент завершается отрицательным результатом, продукт не меняется.

## Внешняя проверка кандидата (только если принят)

Обучение v5 на всех четырёх центрах. Затем:
* **Свежие записи CinC 2018 (MGH):** 149 тестовых записей инкремента 68 (на них выбор параметров не проводился; b = 0), парное сравнение v5 и v4 (оба со сглаживанием по переходам), бутстреп по записям (2000, seed 69):
  прибавка каппы ≥ **+0.005**, нижняя граница ДИ > 0; предохранитель: F1 каждой из W, N2, N3, REM не падает более чем на 0.03.
* **Репликация на COVISLEEP (92 ночи):** нижняя граница ДИ прибавки > −0.005 и точечная оценка ≥ 0.
* Выполнены оба → `sleep.aasm_model` переключается на v5 (хэш в `tests/test_model_inventory.py`), карточка и сводка обновляются; иначе v4 остаётся.

**Ожидание.** Прибавка при leave-one-centre-out +0.005…+0.02 каппы и F1 N1 +0.03…+0.08; рост на CinC меньше, чем на центрах разработки. Вероятность принять v5 по всем критериям — около 40%: гипотеза правдоподобна,
но прежние версии стадировщика не раз упирались в границы центров (D93, D96).

## Ограничения

* Новые признаки — стандартные физиологические, вертекс-волны оцениваются грубо (без морфологии); у ЭОГ при единственном канале (E1) признаки SEM определяются хуже.
* Дизайн C/B сравнивается на тех же центрах, на которых ранее выбирались v3/v4; независимость обеспечивается только внешними проверками (CinC, COVISLEEP).
* Домашняя запись без ЭОГ: нейтральные значения для признаков ЭОГ, как у v4.

## Поправка 1 (до обращения к реальным данным)

При модульном тесте на синтетическом гауссовом шуме порог заметности 5σ дал в среднем 4.4 ложных пика на эпоху (заметность пика над долиной у шума легко превышает 5σ). Порог изменён на **8σ** (ожидание на шуме 0.005 пика/эпоху; проверено только на синтетике, реальные записи не открывались). Остальные определения не менялись.
