# Пре-регистрация инкремента 57: потолок согласия экспертов на PSG-IPA

Зафиксировано до открытия файлов разметки (кроме перечисленного ниже). Метод тот же, что в инкременте 56:
гипотезы и правила записаны до результатов, отрицательное сообщается, продуктовые пороги не подгоняются.

## Зачем

Каппа модели стадирования сна с экспертом — 0.62–0.64 на двух внешних центрах. Неясно, насколько это далеко от
предела: эксперты тоже не согласны друг с другом. Нужно число «эксперт против остальных экспертов» на тех же
стадиях и по той же метрике, чтобы честно сказать врачу, сколько осталось до человеческого уровня.

## Данные

PhysioNet **PSG-IPA** 1.0.0 (CC BY 4.0, открытый доступ): 5 ночных ПСГ для задачи стадирования
(`Sleep_stages/`), каждая размечена **12 независимыми экспертами вручную** (`manual/`), а также полуавтоматически
(`semiauto/`, те же эксперты с компьютерной подсказкой) и автоматически (`auto/`). Каналы: F4-M1, Cz-M1, O2-M1,
E1-M2, E2-M2 — **вместо C4 стоит Cz**, поэтому рабочий путь продукта (F4-C4 / C4-O2) на этих записях не запускается.
Модель на PSG-IPA не оценивается: подмена C4 на Cz была бы новым, непроверенным решением. Тест описательный,
сигналы не открываются, нужны только файлы разметки (`*_SleepStages_*.txt`).

**Что открывалось до пре-регистрации:** список файлов, заголовок EDF записи SN1, первые восемь строк и число
строк файла `SN1_SleepStages_manual_scorer1.txt`, `subject-info.txt`. Согласия экспертов не вычислялось.

## Метрики

Эпохи по 30 с, время начала — из столбца «Recording onset». Стадии W, N1, N2, N3, R; эпохи с меткой «?»
исключаются. Каппа Коэна по 5 классам, по эпохам, оценённым обоими.

1. **Попарное согласие ручных разметчиков:** каппа для каждой из 66 пар, по всем 5 ночам вместе; медиана и
   размах. Бутстреп по ночам (2000, seed 57) для медианы.
2. **Эксперт против консенсуса остальных:** для каждого из 12 экспертов — каппа с мажоритарной стадией остальных 11
   (при ничьей эпоха исключается). Медиана по экспертам и по ночам; F1 по стадиям.
3. **Полуавтоматическая и автоматическая разметка против консенсуса всех 12 ручных.**

## Гипотезы (описательные; решений по продукту они не меняют)

* **H1.** Медиана попарной каппы ручных разметчиков лежит в диапазоне 0.65–0.85 (в литературе ≈ 0.76).
* **H2.** Медиана «эксперт против консенсуса остальных» **выше 0.635** (каппа модели на внешних центрах), то есть
  потолок на этих записях выше модели. Ожидание 0.75–0.85.
* **H3.** Стадия N1 — с наименьшим F1 у экспертов (< 0.60), W и R — с наибольшим (> 0.80).

Правило записи результата: числа вносятся в карточку модели и сводку как контекст («человеческий уровень на
пяти ночах PSG-IPA: …»). Если H2 не выполнена (эксперты согласны хуже модели), это сообщается в карточке дословно.

## Ограничения

* Пять ночей, один набор, 12 разметчиков одной группы: интервалы по ночам широкие.
* Эксперты оценивали одни и те же ночи, консенсус остальных 11 — не «золотой стандарт», а оценка потолка.
* Сравнение с моделью косвенное: другие записи, другая популяция (взрослые с заболеваниями дыхания во сне), модель
  на них не запускалась.
