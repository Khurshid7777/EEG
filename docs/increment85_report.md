# Инкремент 85: экспорт событий для просмотрщиков врача

Что сделано (по обзору эксперта-нейрофизиолога, `docs/expert_neurophysiologist_review_2026-11-28.md`, п. 2): `Pipeline.save_outputs` теперь пишет рядом с отчётом два файла с событиями детекторов.

* `events.tsv` — таблица в стиле BIDS (`onset`, `duration`, `trial_type`, `channels`, `regions`, `confidence`, `learned_probability`; табуляция, UTF-8, `n/a` для отсутствующих значений), события отсортированы по времени, области определены по каналам события (имена T7/T8/P7/P8 приводятся к T3/T4/T5/T6).
* `events.edf` — EDF+ с аннотациями событий (текст «код; ch=каналы; conf=уверенность») и одним плоским каналом на длину записи, чтобы любой EDF+-просмотрщик показал метки на оси времени.

Проверка: тест туда-обратно (запись и чтение через pyedflib: времена, тексты, длительность), тест `save_outputs`, линтер. **Что не проверено:** совместимость с конкретными клиническими просмотрщиками (Natus, Persyst, Nihon Kohden и др.) и со стандартами структурированной отчётности (SCORE EEG) — для этого нужна проверка на этих системах; формат — отправная точка (путь №9 обзора эксперта).

Ограничения: метки только от детекторов (у части событий каналов нет, тогда `n/a`); EDF+-файл содержит плоский сигнал-заглушку и не заменяет исходную запись.
