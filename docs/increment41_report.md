# Инкремент 41: функциональные пробы по меткам записи — реактивность на EEGMMIDB

Пре-регистрация: `docs/preregistration_increment41.md` (зафиксирована до запуска, коммит f7ca0af).
Скрипт: `scripts/run_eegmmidb_reactivity.py`; построчные результаты —
`docs/increment41_eegmmidb.jsonl`, сводка — `docs/increment41_assess.json`. Код — D75.

## Что сделано

* Метки записи (аннотации EDF+, `.vmrk` BrainVision) переносятся в сигнал (`UnifiedSignal.markers`).
* `layer3_features/procedures.py` распознаёт «глаза закрыты/открыты», ГВ (начало/конец), ФС (с
  частотой) на русском и английском и измеряет:
  - основной ритм только на участках с закрытыми глазами;
  - реактивность: насколько подавляется задний альфа-ритм при открывании глаз;
  - нарастание медленной активности (1–8 Гц) в последнюю минуту ГВ и её сохранение через минуту
    после ГВ;
  - усвоение ритма при ФС.
* Раздел «Функциональные пробы» в протоколе RU/UZ и `result_json["procedures"]`. Он **описательный**:
  в модель уровня записи и в заключение не входит.
* `file-check` (строка `annotations`) теперь работает для любого формата и называет, какие пробы
  распознаны.
* Попутно найдено при отладке, до получения результатов: экспорт BCI2000 дополняет имена каналов
  точками («O1..», «Fc5.»). Нормализатор имён теперь их отбрасывает. Без этого затылочные
  электроды не находились, и измерение возвращало пустой результат.

## Результат (109 здоровых добровольцев, EEGMMIDB; R02 «глаза закрыты» + R01 «глаза открыты»)

| | значение | правило |
|---|---|---|
| доля «реактивен» (подавление ≥ 50%) | **0.872** (95 из 109) | H1: ≥ 0.70 — **выполнено** |
| медиана подавления (IQR) | **0.83** (0.67–0.95) | H1: ≥ 0.5 — **выполнено** |
| ритм с закрытыми глазами найден | **0.963** (105 из 109) | H2: ≥ 0.80 — **выполнено** |
| из них в 8–13 Гц | **1.00**; медиана 10.25 Гц | H2: ≥ 0.90 — **выполнено** |

**Решение по пре-регистрации:** модуль включается в отчёт как описательный.

Не реактивны 14 человек:
* у 4 нет выраженного заднего пика с закрытыми глазами (S006, S033, S037, S058) — низкоамплитудный
  альфа-ритм, известный вариант нормы;
* у 10 подавление 0.17–0.50 при пике 9–12 Гц.

Порог 0.5 не менялся.

## Отклонения от плана и ограничения

* S095: первая загрузка R01 оборвалась (curl, код 18 — неполная передача). Эта строка удалена и
  пересчитана один раз; при пересчёте ошибок не было. Как в инкрементах 34–35, это сбой
  инфраструктуры, а не данных.
* S001 и S002 прогонялись во время отладки скрипта тем же кодом. Значения совпали с итоговым
  прогоном.
* Склейка двух отдельных минутных записей — не проба внутри одной записи. Проверено измерение, а
  не распознавание меток в реальном клиническом файле. Распознавание меток проверено тестами на
  русских и английских подписях. ГВ и ФС на реальных данных не проверены: в открытых наборах таких
  меток не найдено.
