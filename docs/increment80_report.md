# Инкремент 80: топография ритмов сна по абсолютной мощности (BOAS) — подтверждена

Пре-регистрация: `docs/preregistration_increment80.md` (до расчёта). Код: `scripts/run_sleep_topography_boas.py`. Результаты: `docs/increment80_assessment.json`, сырьё `docs/increment80_boastopo.jsonl`. Данные: 128 ночей BOAS (одна ночь sub-79 не скачалась).

| Гипотеза | n | Доля ночей | 95% ДИ | Порог | Итог |
|---|---|---|---|---|---|
| H1 N2: log10-сигма (12–15 Гц) центральная > затылочной | 125 | **0.936** | [0.878, 0.972] | ≥ 0.90 | **подтверждена** |
| H2 N3: log10-дельта лобная > затылочной | 58 | **0.983** | [0.908, 1.0] | ≥ 0.90 | **подтверждена** |

Исключения: для N2 — 2 ночи (менее 20 чистых эпох); для N3 — **69 ночи** (менее 20 эпох N3; в BOAS много ночей с малой долей глубокого сна, поэтому H2 проверена на 58 ночах).

Описательно: сигма центр > лоб — 0.66; сигма C4 > C3 — 0.70; **альфа бодрствования затылок > лоб — 0.49** (как на HMC: в ночной ПСГ бодрствование перед сном — с открытыми глазами и артефактами, контроль не работает).

## Вывод

Метрика, предложенная пост-хок в D119, подтверждена на независимом центре с заранее заданным критерием: **абсолютная (log10) мощность** отражает топографию ритмов сна (веретёна центрально, медленные волны лобно). В региональной карте для записей сна по умолчанию используется она (и диапазон «сигма»); относительная мощность сопровождается предупреждением. Решение — D120.

## Ограничения

Шесть каналов, один референт M1; BOAS — смешанная выборка; веретёна не детектировались (спектральная мощность стадии); для N3 доступны лишь 58 ночей; задний альфа в ПСГ не подтверждается.
