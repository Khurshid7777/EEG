# Инкремент 44: основной ритм по бодрым эпохам — отрицательный результат разработки

Только данные разработки: выборка разработки ds005385 из инкремента 43 (100 человек, глаза закрыты
до и после 2 ч заданий). Проверочная выборка инкремента 43 и свежие участники не открывались.
Скрипт — `scripts/dev_pdr_alert.py`, таблица — `docs/increment44_dev.txt`.

## Зачем

В инкременте 43 главным источником ложных отметок при сравнении с прошлой ЭЭГ был основной ритм:
у 10% стабильных людей он «прыгал» больше чем на 1.14 Гц. Гипотеза: в дремоте вершина спектра всей
записи уходит в тету, и по бодрым эпохам ритм будет устойчивее.

## Что сравнивалось

Спектр затылочного среднего (O1/O2) по 4-секундным эпохам. Варианты:
* средний спектр всех эпох;
* средний спектр эпох с наиболее выраженным пиком 4–13 Гц на любой частоте (верхние 50% или 25%) —
  такой отбор не тянет ритм в альфа-диапазон;
* средний спектр эпох с наибольшей долей альфа (50% или 25%);
* медиана частот выраженных пиков по эпохам;
* требование настоящего локального максимума внутри диапазона, а не на его краю.

## Результат

| вариант | ритм найден (до/после) | предел (2.576·RMS) | доля |Δ| > 1.14 Гц |
|---|---|---|---|
| все эпохи | 0.85 / 0.93 | 1.67 Гц | **0.05** |
| выраженный пик, 50% | 0.96 / 0.95 | 3.08 Гц | 0.07 |
| выраженный пик, 25% | 0.97 / 0.98 | 3.09 Гц | 0.12 |
| доля альфа, 50% | 0.96 / 0.95 | 1.90 Гц | 0.10 |
| доля альфа, 25% | 0.97 / 0.97 | 1.93 Гц | 0.12 |
| медиана пиков эпох | 1.00 / 1.00 | 1.91 Гц | 0.09 |
| локальный максимум внутри диапазона | как «все эпохи» | | |

Ни один вариант по бодрым эпохам не устойчивее среднего спектра всех эпох. Отбор находит ритм
чаще, но и чаще «переключается» между пиками.

У четырёх человек с наибольшими скачками причина не в дремоте:
* у двоих быстрый альфа-ритм 12–13 Гц, большинство эпох с пиком 11–13 Гц, и его вершина смещается
  между записями;
* у одного — настоящее замедление на 1.25 Гц после двух часов заданий;
* у одного — дремотное начало первой записи.

Скачки отражают изменчивость самого ритма, а не ошибку измерения.

## Решение

Изменение не даёт выигрыша: пре-регистрация и проверка не проводятся, свежие данные не тратятся.
Основной ритм в сравнении остаётся прежним, с пределом около 1.1 Гц. Отметку только по основному
ритму врач проверяет по записи, и текст сравнения так и говорит (D77). В код добавлена только
функция `peak_utils.peak_from_psd` (общая для `spectral_peak`, поведение не изменилось).
