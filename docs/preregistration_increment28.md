# Пре-регистрация, инкремент 28: тревоги о фоне у новорождённых на наборе Cork (ГИЭ)

> Зафиксировано и опубликовано **до** запуска монитора на любой записи набора Cork. Скачаны
> только `eeg_grades.csv`, `metadata.csv`, `README.md`; сигналы не открывались.

## 1. Почему

Повторный прогон монитора по 79 записям Helsinki с моделью neo2
(`docs/neonatal_monitor_sweep_neo2.json`) дал **196** тревог «вспышка-подавление» — в прежнем
прогоне (`docs/neonatal_monitor_sweep.json`) их было 0. Модель приступов здесь ни при чём:
детектор вспышки-подавления в инкременте 17 переведён на определение ACNS (< 10 мкВ размах,
эпизод по маскам каналов). Прежний «ноль» был артефактом старого метода — средний по каналам
сигнал после усреднённого референта ≈ 0, IBI = 0, и правило D41 (IBI выше нормы для ПМВ)
отсекало всё. То есть проверка D41 «на 79 записях ни одной тревоги» была проверкой сломанного
измерения.

Новые тревоги неслучайны: в 12 из 18 записей детей с тяжёлой асфиксией против 13 из 61
остальных (3.8 против 1.2 тревоги/ч). Но в Helsinki нет экспертной оценки фона, так что
правильность тревог там не проверить. Тревога о вспышке-подавлении у новорождённого —
**критическая** (TZ §10), поэтому её нужно проверить на эталоне.

## 2. Данные — новый, ранее не использованный набор

**Cork HIE grading** (O'Toole et al., 2022; Zenodo 7477575, CC BY 4.0): 169 часовых ЭЭГ
53 доношенных новорождённых с гипоксически-ишемической энцефалопатией (Cork University
Maternity Hospital). Каждый час двумя экспертами по неонатальной ЭЭГ оценён по степени
отклонений фона (Murray et al., 2009) с консенсусом при расхождении:
1 — норма / лёгкие (104 ч), 2 — умеренные (31 ч), 3 — тяжёлые (22 ч), 4 — неактивная (12 ч).
Набор проектом **ни разу** не использовался: ни для разработки, ни для порогов.

## 3. Что запускается (`scripts/cork_grades_eval.py`, код этого коммита, без изменений)

* Монитор как `neurolens monitor --pma 40` (все дети доношенные; ПМВ по детям в наборе нет):
  окна 30 с, шаг 5 с, модель приступов neo2, правила тревог `configs/realtime.yaml`.
* **Тревога о фоне** — тревога типа `burst_suppression` или `suppression` (ACNS-детектор
  вспышки-подавления с правилом D41 и неонатальные категории аЭЭГ BS/неактивная).
* Офлайн-пайплайн (как в харнессе: шаблонный провайдер, без ICA) — только для вторичного
  описания.

Ничего не настраивается на этих данных. Файлы, которые не удалось прочитать, перечисляются и
исключаются (их число публикуется).

## 4. Гипотезы (`evaluation/prereg28.py`), единица — час записи

* **H1** — чувствительность: доля часов степени 3–4 с ≥ 1 тревогой о фоне ≥ **0.70**.
* **H2** — специфичность: доля часов степени 1 без тревог о фоне ≥ **0.80**.
* **H3** — ранговая корреляция Спирмена между степенью и числом тревог о фоне в час ≥ **0.40**.

Часы одного ребёнка зависимы: кроме точных интервалов Клоппера–Пирсона публикуются 95%
интервалы бутстрепа по детям (2000 повторов, seed 0). Гипотезы решаются по точечным оценкам.
Степень 2 входит только в H3 и в описание.

## 5. Правило решения (`prereg28.apply_decision`)

* **H2 подтверждена** → `configs/realtime.yaml: neonatal_background_alarms: critical`
  (как сейчас): тревога о фоне у новорождённых остаётся критической.
* **H2 отвергнута** → `neonatal_background_alarms: review`: у новорождённых тревога о фоне
  становится предупреждением «на просмотр» (WARNING, не критическая находка, лимит 3/ч из
  `realtime.yaml`). Ложная критическая тревога у ребёнка в отделении — вред; при
  недоказанной специфичности тревога не должна быть критической.
* **H1 / H3 отвергнуты** → конфигурация не меняется; чувствительность публикуется как
  ограничение (тяжёлые фоны, не распознанные монитором).

Вторичное, без гипотез: категория аЭЭГ и «не по возрасту» офлайн-отчёта по степеням; часы с
тревогой о приступе при наличии/отсутствии приступов по `metadata.csv`.

## 7. Ограничения

* Один центр, только ГИЭ: «норма» здесь — дети с ГИЭ и нормальным/лёгким фоном, а не здоровые
  новорождённые.
* Степень — оценка всего часа (непрерывность, амплитуда, цикл сна, синхронность, паттерны), а
  тревога — о конкретном паттерне. Степень 3 не обязана содержать вспышку-подавление; поэтому
  порог H1 мягче H2.
* ПМВ 40 нед для всех детей — приближение (доношенные, первые дни жизни).
