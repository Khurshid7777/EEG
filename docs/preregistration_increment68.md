# Пре-регистрация инкремента 68: поправка на избыточное предсказание N1 (CinC 2018, свежие записи; репликация на COVISLEEP)

Зафиксировано до загрузки сигналов новой выборки. Метод — как в инкрементах 52–56.

## Зачем

Разрыв стадировщика `aasm_v4` с экспертами (0.635 против 0.77 между экспертами, `docs/increment57_report.md`) в большей мере приходится на N1. Из матрицы ошибок COVISLEEP (`docs/increment56_assess_covisleep.json`):
N1 составляет 3.9% эпох; полнота N1 0.39, **точность N1 всего 0.16**: модель называет N1 около 8% всех эпох (в основном вместо бодрствования, N2 и REM). Расчёт на той же матрице: если убрать ложные N1,
каппа выросла бы на 0.10 (верхняя оценка); при реалистичном улучшении N1 с F1 0.22 до 0.40 — примерно на +0.06. Самое дешёвое средство — **сдвиг априорной вероятности N1**: вычитание константы
из логарифма вероятности N1 перед выбором стадии и сглаживанием Витерби. Это одна настраиваемая величина (не новая модель).

## Что меняется

* Параметр `aasm_n1_logit_offset` (b ≤ 0; по умолчанию 0 — поведение прежнее): `log p'(N1) = log p(N1) + b`, вероятности перенормируются, затем argmax и Витерби (матрица переходов та же).
  Только путь AASM (`aasm_v4`).

## Выборки (свежие записи CinC 2018, MGH)

CinC training: 994 записи; исключены `tr03-0005` и записи инкрементов 52 (150) и 55 (150, seed 53). Из оставшихся 693 берутся (seed 68) 300 записей: **150 «разработка», 150 «тест»** (первые 150 в отсортированном
случайном порядке — разработка, остальные — тест). Тестовые записи не используются для выбора b. Репликация: 92 ночи COVISLEEP (использовались ранее как тест v4; это раскрывается).

## Выбор b (только на «разработке»)

Сетка b ∈ {0, −0.25, −0.5, −0.75, −1.0, −1.25, −1.5, −2.0}; критерий — наибольшая объединённая каппа со сглаживанием по 150 записям; при равенстве (разность < 0.001) — меньшее |b|.

## Правило решения (все условия должны выполниться)

1. **Тест CinC (150 записей):** прибавка каппы (b* против 0, парный бутстреп по записям, 2000, seed 68) ≥ **+0.005**, нижняя граница ДИ > 0.
2. **Предохранитель:** F1 N1 не падает, а F1 каждой из W, N2, N3, REM — не более чем на 0.03.
3. **Репликация на COVISLEEP:** прибавка каппы (b* против 0) нижняя граница парного ДИ > −0.005 и точечная оценка ≥ 0.
* Выполнены все три → `aasm_n1_logit_offset: b*` в `configs/sleep.yaml`; в сводках и карточке — числа. Иначе поведение не меняется, результат сообщается.

**Ожидание.** b* около −0.75…−1.25; прибавка на тесте +0.01…+0.03; F1 N1 с 0.43 до 0.47–0.52. Не уверен: ложные N1 часто совпадают с реальной сонливостью («пограничные» эпохи), а полнота N1 может упасть.

## Ограничения

* Поправка на априорную вероятность — грубое средство; настоящие новые признаки N1 (вертекс-волны, замедление альфа-ритма, медленные движения глаз) остаются отдельной работой.
* Одна больница (MGH) для выбора и теста; COVISLEEP — единственная репликация (взрослые с бессонницей, другой прибор).
* Уверенность модели по эпохам не пересчитывается (`mean_confidence` в отчёте считается после поправки).
