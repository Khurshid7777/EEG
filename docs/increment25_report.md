# Инкремент 25: устойчивость заключения к отличиям регистрации

> Данные: `docs/increment25_perturb.json`; харнесс `scripts/run_routine_perturb.py`. Оценочная
> часть NMT (185 записей), те же записи с изменённой регистрацией. Ничего не настраивалось.

Записи других приборов отличаются частотой дискретизации и набором электродов. Те же записи
пересчитаны с типичными отличиями:

| | AUC | Специфичность | Чувствительность | Совпадение вердикта с исходным | Медиана |Δ оценки| | Совпадение правил |
|---|---|---|---|---|---|---|
| исходные (200 Гц, 19 + A1/A2) | 0.933 | 0.789 | 0.833 | — | — | — |
| 256 Гц | 0.934 | 0.779 | 0.844 | 0.957 | 0.002 | 0.973 |
| без ушных A1/A2 | 0.928 | 0.789 | 0.833 | 0.957 | 0.012 | 0.984 |
| без срединных Fz/Cz/Pz | 0.926 | 0.779 | 0.833 | 0.941 | 0.021 | 0.935 |

**Вывод:** заключение устойчиво к этим отличиям — признаки модели в основном относительные
(доли мощности, оценки обученных моделей, сравнение с собственным фоном). Расхождения (4–6%)
приходятся на пограничные оценки (инкремент 23).

**Ограничения:** это моделирование отличий на записях одного прибора; другие фильтры,
импеданс, шум, электродные системы и популяции пациентов проверяются только новой базой
(NMT-4K-EEG — вторая больница).

## Усиление (коэффициент амплитуды) — найдена уязвимость, модель заменена

Абсолютная амплитуда различается между приборами и референтами (в самой NMT была ошибка единиц
×100). Те же записи с усилением ×0.7 и ×1.4 (`docs/increment25_gain.json`):

| Оценочная часть | v1 (с амплитудой) | v2 (без абсолютной амплитуды) |
|---|---|---|
| исходные: AUC / спец. / чувств. | 0.933 / 0.789 / 0.833 | 0.897 / 0.789 / 0.800 |
| ×0.7: спец. / чувств. / совпадение вердикта | 0.779 / 0.744 / 0.84 | 0.853 / 0.756 / 0.92 |
| ×1.4: спец. / чувств. / совпадение вердикта | **0.547** / 0.844 / 0.84 | **0.726** / 0.811 / 0.95 |
| AUC вне фолда (разработка, 1 045) | 0.869 | 0.861 |
| правила (для сравнения), ×1.4: спец. / чувств. | 0.716 / 0.811 | |

v1 выучил абсолютную амплитуду одного прибора: при усилении ×1.4 почти половина нормальных записей
получала «отклонения». `record_gbm_v2` (тот же признаковый набор без `robust_amplitude_uv`, та же
процедура, пороги по возрасту и вариант без возраста — `docs/increment25_cv_v2*.json`) теряет на
«своём» приборе немного (AUC вне фолда −0.008), а сдвиг усиления переносит намного лучше. Остаток
зависимости — через пороги детекторов в мкВ (правила при ×1.4 — 0.72 / 0.81).

**Решение:** заключение решает v2; v1 остаётся в репозитории (откат — две строки
`configs/impression.yaml`). Числа v2 на оценочной части (0.789 / 0.800) — post-hoc и сообщаются
как таковые; пограничная зона (инкремент 23) подобрана для v1 и не перенастраивалась.
