# Пре-регистрация инкремента 77: привязка события к каналам и областям (NMT-Events, тестовая часть)

Зафиксировано до чтения сигналов тестовой части. Открыты только CSV-разметка (каналы и комментарии, уже использованные в инкрементах 12–15) и определения. Продолжение D116: часть детекторов не указывает каналы события, и карта пишет «без привязки к каналам».

## Вопрос

Если время события известно (из детектора или врача), можно ли **по сигналу** надёжно определить, над какой областью и в каком полушарии оно максимально выражено? Проверяется отдельно от детекции: берётся время события из экспертной разметки, локализатор видит только сигнал.

## Данные

NMT-Events, **тестовая часть** (49 аномальных записей: нечётные номера, `split_by_rule`; 2 910 эпилептиформных аннотаций с каналами). Тестовая часть уже использовалась для оценки детектора (инкременты 15–20), но не для локализации; параметры локализатора не подбираются (ниже), обучающая часть не нужна. События: категория «эпилептиформные» (`spike|sharp|poly`); замедление — описательно отдельно. 19 стандартных каналов 10-20; события, у которых нет ни одного стандартного канала, исключаются и считаются.

## Локализатор (основной вариант A, фиксирован здесь)

Сигнал: общий средний референт по 19 электродам, полосовой фильтр 2–40 Гц (Баттерворт 4-го порядка, нулевая фаза). Окно события: [начало − 0.1 с, конец + 0.1 с] (для точечных событий — ±0.15 с вокруг начала). Для каждого электрода: максимум |x| в окне, делённый на робастную σ (1.4826·MAD) электрода по всей записи. **Предсказание = электрод с наибольшим значением** (top-1); топ-3 — вторично. Область и полушарие — по определениям из инкремента 73 (срединные Fz/Cz/Pz — «срединные»).

Варианты чувствительности (оцениваются, не выбираются): **B** — тот же расчёт по отрицательному пику (min x), **C** — энергия второй производной (острота) вместо |x|.

## Метрики

* **M1 (канал):** top-1 ∈ экспертный набор каналов события. Базовая линия — случайный канал: средняя доля |набор|/19.
* **M2 (область):** область top-1 ∈ множеству областей экспертных каналов. Базовая линия — случайный канал (расчётная) и «всегда самая частая область».
* **M3 (полушарие), только односторонние события:** все экспертные каналы (кроме срединных) в одном полушарии и их ≥ 1; предсказанное полушарие равно экспертному; срединное предсказание — промах.
Доверительные интервалы — бутстреп по записям (2000, seed 77), так как события внутри записи зависимы.

## Гипотезы и правила решения

* **H1 (полушарие):** M3 ≥ **0.75** и нижняя граница ДИ > **0.60**.
* **H2 (область):** M2 ≥ **0.60** и выше базовой линии «случайный канал» не менее чем на **0.15** (абсолютно).
* **H3 (канал):** M1 ≥ **0.40** и не менее чем вдвое выше базовой линии «случайный канал».
Если H1 и H2 выполнены — привязка события к области по сигналу включается в карту как «оценка по сигналу» (иначе, чем канал от детектора, с отдельной пометкой); если H1 не выполнена — события без каналов остаются «без привязки»; результат по M2/M3 публикуется в любом случае.

## Ожидания

Положение пика спайка на скальпе при общем среднем референте нередко смещается на соседние электроды; ожидаю M3 ≈ 0.70–0.85, M2 ≈ 0.55–0.70, M1 ≈ 0.25–0.40. Вероятность H1 ≈ 55%, H2 ≈ 45%, H3 ≈ 30%.

## Ограничения

Эксперты размечали каналы «где виден разряд», а не источник; события со множеством каналов дают большие множества и завышают M1/M2 — поэтому базовая линия «случайный канал» считается по размеру набора каждого события; референт набора A1/A2 заменён общим средним (разметка делалась по записи с другим референтом); единицы амплитуды в файле неверны (D43) — не влияют, т.к. нормировка по каналу; одна страна, один прибор.
