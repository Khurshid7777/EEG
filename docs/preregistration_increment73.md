# Пре-регистрация инкремента 73: региональная карта коры — физиологические контроли (фаза B плана `plan_regional_activity_2026-11-26.md`)

Зафиксировано до написания кода региональных признаков и до расчёта по данным. Решения владельца проекта (2026-11-26): уровень — **доли и полушария** (скальповое картирование, не источники); визуализация — «диагностика + карта» (интерактивная страница + PDF, фаза C позже); проверку начинаем с **физиологических контролей** на открытых данных.

## 1. Что измеряем (определения заданы здесь и не подбираются)

**Области (по 19 электродам 10-20; T7/T8/P7/P8 нормализуются в T3/T4/T5/T6):**
| Область | Электроды |
|---|---|
| лобная | Fp1, Fp2, F3, F4, F7, F8, Fz |
| центральная | C3, C4, Cz |
| височная | T3, T4, T5, T6 |
| теменная | P3, P4, Pz |
| затылочная | O1, O2 |
Полушарие: нечётный индекс — левое, чётный — правое, `z` — срединное.

**Метрика.** Сигнал после нашей стандартной предобработки, референт — **среднее по 19 электродам** (чтобы результат не зависел от референта прибора), Уэлч 4-секундные окна с 50% перекрытием, мощность в полосе / мощность в 1–30 Гц (относительная мощность): альфа 8–12 Гц, тета 4–8 Гц. Региональное значение — среднее по электродам области. Отбрасываются окна с размахом > 200 мкВ (грубые артефакты).
**Индекс асимметрии** гомологичной пары (правый − левый): AI = ln(P_правый / P_левый) по абсолютной мощности альфа.

## 2. Данные

* **ds003775** (Осло, 111 здоровых, закрытые глаза, 64 электрода → берутся 19 электродов 10-20 по именам);
* **ds004504 контроли** (Иоаннина, 29 здоровых, закрытые глаза, 19 электродов, референт A1-A2);
* **eegmat** (36 здоровых): `_1` фон (покой), `_2` счёт. Условие глаз в `_1` авторы не указывают — результат по нему описывается, но H1 для eegmat — только описательная.
Все записи берутся как есть, без исключений, кроме нечитаемых (публикуются числом).

## 3. Гипотезы и правила решения

* **H1 — затылочно-теменной максимум альфа.** В каждом из двух наборов с закрытыми глазами (ds003775, ds004504 контроли) максимум региональной относительной альфа приходится на затылочную или теменную область в **≥ 90%** записей. Вторично, описательно: доля записей с максимумом именно в затылочной области.
* **H2 — эффект счёта (eegmat, парный по испытуемым).** (а) относительная тета лобной области выше при счёте, чем в покое, у **> 50%** испытуемых (односторонний точный биномиальный тест, α = 0.05, точный ДИ Клоппера—Пирсона для доли); (б) относительная альфа затылочно-теменных областей (затылочная + теменная вместе) ниже при счёте, чем в покое, у > 50% испытуемых (тот же тест). Подтверждена та гипотеза, у которой выполнены оба условия: доля > 0.5 и p < 0.05.
* **H3 — межполушарная симметрия у здоровых.** Медиана |AI| по паре O1–O2 (абсолютная альфа) < **0.20** (разница мощностей порядка 22%) в каждом из двух наборов закрытых глаз; описательно — для пар F3–F4, C3–C4, T3–T4, P3–P4, F7–F8, T5–T6.

Если не подтверждена H1 или H3 — метрика «карта по относительной альфа» в продукт не включается, причина разбирается в отдельном инкременте; если не подтверждена H2 — формулировки про «эффект нагрузки» не используются. Пороги по данным не подбираются.

## 4. Ожидания

H1: затылочно-теменной максимум ≈ 95% (по относительной мощности после усреднённого референта максимум может «уезжать» в теменные электроды; затылочная область — 60–80%). H2: лобная тета ↑ у 65–80% испытуемых (вероятность подтверждения 80%); спад альфа при счёте у 70–90% (85%). H3: медиана |AI| 0.05–0.15 (80%).

## 5. Ограничения

Здоровые добровольцы; закрытые глаза; 19 электродов дают скальповое, а не источниковое картирование; относительная мощность с общим средним референтом зависит от числа электродов; в eegmat сигнал уже очищен автором (ICA), `_2` — когнитивная нагрузка; региональные «функции» — ориентировочная интерпретация ритмов, не прямое измерение функции коры. Фаза B3 (очаги) и визуализация (фаза C) этой пре-регистрацией не покрываются.
