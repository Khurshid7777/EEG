# Инкремент 23: устойчивость заключения (тест-ретест) и пограничная зона

> Данные: `docs/increment23_halves.json` (оценочная часть NMT), `docs/increment23_halves_dev.json`
> (1 045 записей разработки); харнесс `scripts/run_routine_halves.py`. Тестовые выборки не
> тратились: изменение не меняет ни одно бинарное решение, только формулировку.

## 1. Вопрос

Если проанализировать первую и вторую половину одной и той же записи (~6 мин каждая), совпадёт ли
вывод «норма/отклонения»? Клинически это минимальное требование: одна и та же ЭЭГ — один и тот же
вывод.

## 2. Результат (оценочная часть, 185 записей)

| | Совпадение вердикта половин | Каппа Коэна |
|---|---|---|
| модель уровня записи | 0.784 | 0.571 |
| правила | 0.805 | 0.611 |

Оценки половин коррелируют (r = 0.79), AUC на половинах почти не падает (0.933 и 0.911 при 0.933
на полной записи): различение сохраняется, но у записей с оценкой **около порога** вердикт
переворачивается. Каждая пятая запись получала бы разный ответ от двух половин.

## 3. Пограничная зона

Ширина зоны вокруг порога (в логит-шкале) выбрана на половинах **записей разработки** по заранее
заданной цели: вне зоны вердикты половин расходятся не чаще чем в 10% пар — **0.85** (9.7%).

| | Расхождение вне зоны | Доля пограничных половин | Специфичность / чувствительность вне зоны |
|---|---|---|---|
| разработка (1 043 пары) | 0.097 | 0.30 | 0.84 / 0.91 |
| оценочная часть (185 пар) | **0.095** | 0.26 | 0.83 / 0.89 |

На **полных** записях оценочной части пограничными оказываются 27%. Для них заключение говорит:
«пограничная совокупная оценка … вывод неустойчив и требует решения врача»; бинарное решение
(для статистики) не меняется, находки правил перечисляются как прежде.

## 4. Урок

Точность заключения и его устойчивость — разные свойства; второе почти не проверяется, а клинически
важно не меньше. Около четверти рутинных записей находятся там, где ни правила, ни модель не дают
воспроизводимого ответа, — и отчёт теперь это говорит, а не выбирает наугад.
