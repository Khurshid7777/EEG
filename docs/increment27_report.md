# Инкремент 27: ритмичность для выявления приступов у новорождённых

> Данные: Helsinki neonatal EEG (79 новорождённых, 330 консенсусных приступов). Эксперимент:
> `scripts/neonatal_rhythm_experiment.py` → `docs/increment27_neonatal_rhythm.json`; трассы и модель:
> `scripts/neonatal_rt_traces.py`, `scripts/train_neonatal_neo2.py` → `docs/increment27_neo2_report.json`,
> `configs/models/ictal_gbm_realtime_neo2.json`, `configs/calibration.ml_realtime_neo2.json`.

## 1. Вопрос

Неонатальный монитор находил около половины приступов (0.45 на тестовой половине, инкремент 12).
Признаки модели — амплитуда относительно своего фона, спектральная концентрация, доминирующая
частота, относительные мощности — не измеряют **повторяемость**, а неонатальный приступ — это
продолжающиеся ритмичные разряды.

## 2. Признак

Для каждой эпохи и канала — максимум автокорреляции сигнала 0.5–8 Гц на лагах 0.15–2 с в 8 с,
заканчивающихся концом эпохи (причинно: монитор не видит будущего); по каналам — максимум,
среднее трёх лучших, доля каналов ≥ 0.6, период; плюс отклонение от медианы за последние ~5 мин
(`layer3_features/rhythm_ac.py`, версия признаков 5; офлайн и потоковый расчёт совпадают — тест).

## 3. Результат (кросс-валидация по пациентам, 10 фолдов, все 79 записей)

Офлайн-признаки, причинная оценка событий, одинаковый подбор пост-обработки:

| Ложных тревог/ч | v1 | v1 + ритмичность |
|---|---|---|
| ≤ 1 | 0.33 | **0.42** |
| ≤ 2 | 0.46 | **0.58** |
| ≤ 4 | 0.59 | **0.70** |

Трассы монитора (то, что видит монитор в работе), рабочая точка neo1 (0.5 / ≥ 20 эпох) без
перенастройки:

| | Найдено приступов | Ложных тревог/ч | Задержка (медиана) |
|---|---|---|---|
| признаки v1 (как neo1) | 0.606 | 3.53 | 23 с |
| **признаки v5 (neo2)** | **0.661** | **3.16** | 26.5 с |

(Лучшая точка сетки для v5 при ≤ 3.53 тревог/ч — 0.676 при 0.8 / ≥ 3 — не взята: выбор на тех же
данных.)

## 4. Решение и ограничения

Монитор у новорождённых — `ictal_gbm_realtime_neo2` в той же рабочей точке, калибровка Platt по
событиям вне фолда (точность тревог 0.38). Откат — модель neo1 в `configs/ml.yaml`.

* **Не независимая проверка:** тестовая половина Helsinki уже использована (инкремент 12); оценка —
  кросс-валидация по пациентам на всех 79, финальная модель обучена на всех 79. Числа CV выше
  тестовой оценки инкремента 12 (0.45), потому что половина данных тогда была тестовой, а модель
  обучалась на 40 новорождённых; сравнение v1/v5 корректно только внутри одной и той же CV.
* Один центр (Хельсинки); перенос — на другой неонатальной базе.
* Расчёт ритмичности добавляет к работе монитора у новорождённых ~2 мин на час записи.

## 5. Сквозная проверка реальным монитором (eeg13, 4.3 ч, 5 приступов)

`neurolens monitor --pma 40` с neo2: 22 тревоги (5.1/ч, бюджет 10), задержка анализа окна ~0.3 с
(работа в реальном времени возможна). Все 5 приступов дали тревогу; одна тревога о приступе вне
приступов (как и с neo1). Одна тревога «вспышка-подавление» — сразу после конца 500-секундного
приступа (1290–1320 с; вероятно, постиктальное подавление). Детектор подавления не менялся;
с neo1 эта тревога, по-видимому, поглощалась соседними тревогами о приступе — отмечено для
следующего прогона по всем 79 записям.
