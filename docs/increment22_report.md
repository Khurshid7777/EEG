# Инкремент 22: оценка аномальности уровня записи решает заключение

> `configs/models/record_gbm_v1.json`, CV: `docs/increment22_cv.json`; прогон:
> `docs/increment22_eval.json`; оценка: `docs/increment22_assessment.json`.

## 1. Итог — оценочная часть NMT (второе использование, оговорено заранее)

| Заключение | Специфичность (95% ДИ) | Чувствительность (95% ДИ) | Сбаланс. точность |

Гипотезы:

Решение (H1 ∧ H2 ∧ H3):

* record_model_decides: **да**

AUC модели на оценочной части — **0.933** (на разработке вне фолда — 0.869). Правило применено
кодом: `record_model_decides: true`, `impression.yaml` — числа модели (0.758 / 0.867).

## 2. Что это значит

При той же специфичности (0.76 против 0.77) модель находит на 7 аномальных записей больше:
чувствительность 0.79 → 0.87. Решающие признаки — не отдельная находка, а их совокупность:
распределение оценок обученной модели разрядов, фон и ЗДР с поправкой на возраст, события модели
приступов (теперь «кандидаты»). Находки правил остаются в заключении — как то, что врачу надо
просмотреть, — но решение «норма/отклонения» принимает оценка записи.

## 3. Попутно: независимое подтверждение инкрементов 18–20

Оценочная часть не использовалась с инкремента 17. Правила текущего пайплайна на ней:
специфичность **0.768**, чувствительность 0.789; в инкременте 17 на тех же записях было 0.589 /
0.844. Улучшение специфичности правил, найденное на подвыборках обучающей части, повторилось на
записях, которых разработка не касалась.

## 4. Ограничения

* Второе использование тестовой выборки: она не участвовала в разработке, но уже была тестом;
  результат слабее первой проверки.
* Один центр (NMT, Пакистан), одна группа неврологов; перенос на другие центры не проверен.
  Следующая проверка — NMT-4K-EEG (вторая больница; доступ по заявке) или другая база.
* Модель зависит от выходов текущих детекторов: любое их изменение требует переобучения и
  новой проверки.

## 5. Поправка после проверки (post-hoc): пороги по возрасту

Разбор по возрастным группам показал то, чего не видно в общих числах: у **нормальных детей
2–11 лет** специфичность модели — 0.41 вне фолда на разработке и **0.28** на оценочной части (у
правил 0.58 и 0.72): почти три из четырёх нормальных детей получали «признаки отклонений». В NMT
половина аномальных записей — дети, и модель частично выучила возраст как довод. У младенцев (< 2 лет)
наоборот — специфичность высокая, чувствительность низкая.

Пре-регистрированная цель — специфичность 0.75 — теперь выполняется **в каждой возрастной группе**
(< 2, 2–11, 12–17, 18–59, ≥ 60 лет; пороги 0.139 / 0.506 / 0.269 / 0.102 / 0.230 по предсказаниям
вне фолда, `docs/increment22_cv.json`):

| | Специфичность | Чувствительность |
|---|---|---|
| разработка, вне фолда: один порог → пороги по возрасту | 0.750 → 0.749 | 0.828 → 0.797 |
| оценочная часть (post-hoc): один порог → по возрасту | 0.758 → **0.789** | 0.867 → 0.833 |
| дети 2–11 лет, оценочная часть | 0.28 → **0.72** | 0.86 → 0.63 |
| взрослые 18–59 лет, оценочная часть | 0.89 → 0.80 | 0.87 → 1.00 |

Это **поправка после проверки**: оценочная часть использована уже дважды, и числа с порогами по
возрасту не подтверждены новой выборкой. Принята потому, что один порог нарушал саму
пре-регистрированную цель в подгруппе, где ложная «патология» ведёт к гипердиагностике эпилепсии
у детей. `impression.yaml` сообщает врачу числа действующего правила (0.789 / 0.833) и помечает их
как post-hoc; откат — удалить `record_threshold_by_age`. Подтверждение — на новой базе
(NMT-4K-EEG).
