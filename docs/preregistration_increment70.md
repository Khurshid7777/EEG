# Пре-регистрация, инкремент 70: специфичность на здоровых — eegmat (PhysioNet, Харьков)

> Зафиксировано **до** запуска пайплайна на сигналах. Открыты только `README.txt`, `subject-info.csv` и заголовок одной записи (`Subject00_1.edf`: 19 электродов 10-20 + A2-A1 + ЭКГ, 500 Гц, ~182 с); результат ни одной записи не рассчитывался.

## 1. Зачем

Дополнительная независимая норма (другой центр — Украина, прибор Neurocom 23 канала, ушной референт, 36 здоровых взрослых) к уже проверенным: ds003775 (111, специфичность 0.964), ds004504 (29), NMT-норма (95). Цель — убедиться, что ранее наблюдаемая специфичность не специфична для этих центров.

## 2. Данные и особенности (известны заранее)

* eegmat v1.0.0 (PhysioNet, открытый), 36 здоровых, по два EDF: `_1` — фон до задачи (покой, ~3 мин), `_2` — **во время устного счёта** (когнитивная нагрузка; это не клиническая норма покоя).
* Автор данных очищал сигнал ICA (глаза, мышцы, ЭКГ); применён низкочастотный фильтр и сетевой режектор 50 Гц. Это **упрощает** задачу и занижает число артефактных ложных находок.
* Возраст берётся из `subject-info.csv`; пол не используется.

## 3. Прогоны (`scripts/run_eegmat_eval.py`, код этого коммита)

Пайплайн как в инкременте 34 (шаблонный провайдер, без ICA, модель уровня записи с порогами по возрасту и пограничной зоной), ничего не настраивается:
* **основной — фон (`_1`)**, 36 записей;
* **вторичный — задача счёта (`_2`)**, 36 записей.
Каналы: 19 электродов 10-20 как есть (A2-A1 и ЭКГ исключаются стандартной нормализацией пайплайна; если нет — выбираются явно STANDARD_1020).

## 4. Гипотеза и правило решения

* **H1** — специфичность (доля без «отклонений») в основном прогоне ≥ **0.65** (тот же порог, что в инкременте 34).
* Описание, без решающих правил: специфичность в `_2`, доля пограничных, какие находки дают «отклонения», доля записей, по которым модель уровня записи не принимает решение (`decides == false`; такие записи считаются в знаменатель отдельно и публикуются числом, как «исключённые»).
* **Ожидание:** специфичность 0.85–0.95 (ожидание ниже, чем у ds003775: записи короче, возраст молодой; ICA-очистка скорее помогает). Вероятность H1 около 90%.

## 5. Воспроизведение

```bash
PYTHONPATH=src python scripts/run_eegmat_eval.py docs/increment70_rest.jsonl --suffix 1
PYTHONPATH=src python scripts/run_eegmat_eval.py docs/increment70_task.jsonl --suffix 2
PYTHONPATH=src python scripts/run_eegmat_eval.py --assess docs/increment70_rest.jsonl docs/increment70_task.jsonl docs/increment70_assessment.json
```

## 6. Ограничения

Здоровые по анкете; фрагменты ~3 мин; ICA-очистка автором; режим задачи не клиническая норма; 36 человек — доверительный интервал специфичности широкий (≈ ±0.10). Тест показывает отсутствие грубой регрессии на новой норме, а не точную оценку специфичности.
