# Пре-регистрация инкремента 81: нужны ли возрастные нормы межполушарной асимметрии

Зафиксировано до расчёта. Новые сигналы не загружаются: используются значения асимметрии AI (ln P_правый / P_левый, абсолютная альфа, общий средний референт) из инкрементов 73–74 и возраст из таблиц участников. Раскрытие: в инкременте 74 были показаны описательные корреляции |AI| с возрастом на ds003775 (от −0.14 до +0.11, слабые); подтверждающая проверка ниже задаёт формальные правила.

## Данные и возраст

* **Обучающая выборка:** ds003775 (n = 99 после исключений инкремента 73; возраст 17–71 из `participants.tsv`; один прибор BioSemi, один референт).
* **Удержанные здоровые:** ds004504 контроли (n = 29; возраст из `participants.tsv`) и eegmat фон (n = 36; возраст из `subject-info.csv`) — те же, что в инкременте 74.
Возраст и AI в разных наборах смешаны с прибором и референтом, поэтому ассоциация с возрастом оценивается **только внутри ds003775**.

## Шаг 1 — есть ли зависимость от возраста

Для каждой из семи пар: ранговая корреляция Спирмена возраста с **AI** (сдвиг медианы) и с **|AI|** (разброс), всего 14 проверок; поправка Холма, α = 0.05.
**Решение:** если ни одна проверка не значима после поправки — возрастные нормы **не нужны** (остаются объединённые пределы инкремента 74), инкремент на этом заканчивается. Если значима хотя бы одна — шаг 2 для соответствующих пар.

## Шаг 2 — возрастные пределы (только для значимых пар)

Квантильная регрессия AI на возраст (линейная, квантили 0.025 и 0.975; `sklearn.linear_model.QuantileRegressor`, alpha = 0) по ds003775. Проверка на удержанных здоровых (n = 65): доля записей вне возрастных пределов против доли вне объединённых пределов, по значимым парам.
**Решение:** возрастные пределы принимаются для пары, если |доля − 0.05| с возрастными пределами меньше, чем с объединёнными, не менее чем на 0.02, и доля не превышает 0.12; иначе пара остаётся с объединёнными пределами.

## Описательно

Доля вне объединённых пределов отдельно в ds004504 (возраст старше) и eegmat (моложе); диапазоны возраста по наборам.

## Ожидание

Возрастные нормы не нужны (шаг 1 не даёт значимых проверок), вероятность ≈ 80%; если для одной пары зависимость значима (вероятнее — разброс |AI| растёт с возрастом), возрастные пределы вряд ли улучшат результат на 65 удержанных записях.

## Ограничения

Один обучающий прибор; возрастной диапазон 17–71; 99 записей — мощность невелика для малых эффектов (|ρ| < 0.3); возраст в удержанных наборах ограничен (eegmat 16–26 лет, ds004504 около 60–80 лет), поэтому отсутствие эффекта не доказывает отсутствие зависимости во всей популяции.
