# Инкремент 52: стадирование монтажа AASM включено — положительный результат

Пре-регистрация: `docs/preregistration_increment52.md` (коммит 903d00f). Разработка —
`scripts/dev_aasm_stager_v4.py` (`docs/increment52_dev_loco.json`, `docs/increment52_dev_eog.json`,
`docs/increment52_dev_window.json`); проверка — `scripts/run_cinc2018_sleep.py`
(`docs/increment52_assess_cinc2018.json`). Решение — D94.

## Что изменено (на разработке, четыре центра, 416 ночей)

1. Нормировка признаков игнорирует пропуски сигнала (дефект: одна NaN-эпоха обнуляла признак на всю
   ночь; 24 ночи EESM19).
2. Добавлены ненормированные мощности медленных волн (абсолютная амплитуда — критерий N3 по AASM).
3. Период сна на монтаже AASM: склеиваются пробуждения < 2 ч (было < 30 мин; дефект: половина ночи
   с долгим пробуждением считалась бодрствованием).
4. При одном глазном электроде используется он сам, а не нейтральная ЭОГ.

LOCO-каппа в среднем по центрам: 0.565 (v3) → 0.610. Прогноз до теста — около 0.59, на пороге.

## Решение

По пре-регистрированному правилу `sleep.aasm_model` = v4 в `configs/sleep.yaml`: стандартный
монтаж ПСГ (F4/C4/O2 против сосцевидных) теперь стадируется.

## Поправки и раскрытия

* **Тест инкремента 50 был затронут дефектом пропусков:** каппа v2 на EESM19 (0.559) получена с
  дефектом. Решение D92 не пересматривается: v2 не используется.
* Прогноз до теста (≈ 0.59) оказался ниже результата (0.62); разница в пределах разброса LOCO
  (0.54–0.67).
* Каппа 0.62 — «существенное» согласие, но ниже согласия двух экспертов между собой на EESM19
  (0.84). Это вспомогательная гипнограмма для врача, а не замена ручной разметки.

## Ограничения

* Проверено на взрослых в лабораторной ПСГ; дети и домашние записи без пары ЭОГ не проверены.
* BOAS остаётся самым трудным центром (LOCO 0.54, N3 F1 0.35) — причина не установлена.
* Возраст и диагнозы тестовой когорты в использованных файлах не указаны.
