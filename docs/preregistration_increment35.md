# Пре-регистрация, инкремент 35: чувствительность заключения на ЭЭГ в коме после остановки сердца (I-CARE)

> Зафиксировано **до** загрузки сигналов ЭЭГ: скачаны только `RECORDS`, файлы пациентов `.txt`
> (больница, возраст, исход) и заголовок `.hea` одного сегмента; ни один сигнал не открывался.

## 1. Зачем

Инкременты 33–34 проверили на двух чужих центрах только **специфичность** (136 из 140 здоровых
без «отклонений»), причём оценка модели на чужих приборах ниже, чем на NMT: заключение там
«осторожнее». Неизвестно, не пропускает ли оно патологию на чужом приборе. TUAB ждёт
регистрации. I-CARE — открытый набор, где ЭЭГ **заведомо патологическая**: взрослые в коме после
остановки сердца, другие страны (Нидерланды, Бельгия, США), больницы и приборы.

## 2. Данные

PhysioNet I-CARE v2.1 (Amorim et al., 2023; CC BY-NC-SA 4.0), открытая часть: **607 пациентов**,
больницы A (261), B (120), D (83), E (74), F (69); исход по шкале CPC: плохой (3–5) — 382,
хороший (1–2) — 225; возраст 16–90 (медиана 63, у одного не указан — заключение по модели без
возраста, как в рабочей конфигурации). ЭЭГ — 19 электродов 10-20, 500 Гц (по заголовку),
сегменты по часу, формат WFDB.

**Ожидаемое заключение у всех — «отклонения»**: кома (ШКГ ≤ 8) в первые сутки после остановки
сердца — ЭЭГ без нормального фона бодрствования (подавление, вспышка-подавление, диффузное
замедление, периодические разряды); это верно и при хорошем исходе. Меток ЭЭГ нет.

Известно заранее и потому фиксируется здесь:
* **единицы не указаны** (в заголовках «nu»); значения считаются микровольтами, как
  получил бы их пайплайн. Правило: больница, у которой медиана (по записям) медианного по
  каналам СКО сигнала вне **1–300 мкВ**, считается больницей с неизвестным масштабом и
  исключается из H1 (сообщается отдельно; число «все больницы» тоже публикуется);
* седация, гипотермия и артефакты реанимации не удалялись (как в наборе);
* модель уровня записи обучена на рутинной ЭЭГ бодрствования (NMT) — кома вне её домена;
  проверяется именно перенос.

## 3. Отбор и прогон (`scripts/run_icare_eval.py`, `datasets/icare.py`, код этого коммита)

* У каждого пациента один сегмент: ближайший к **24 ч** после восстановления кровообращения
  (при равенстве — более ранний) среди сегментов с ≥ **20 мин** ЭЭГ (по заголовку).
* Анализируются его **первые 20 минут** (длительность рутинной ЭЭГ; загрузка — запросом
  диапазона байтов), все каналы ЭЭГ как есть.
* Пайплайн как в харнессе рутинной ЭЭГ (без ICA, шаблонный провайдер), заключение — модель
  уровня записи v2 с порогами по возрасту и пограничной зоной. Ничего не настраивается.
  Нечитаемые записи, пациенты без подходящего сегмента и записи без оценки исключаются и
  публикуются числом.

## 4. Гипотезы и правило решения (`evaluation/prereg35.py`)

* **H1** — чувствительность (доля заключений «отклонения») в больницах с правдоподобной
  амплитудой ≥ **0.80**.
* **H2** — AUC оценки модели уровня записи, плохой исход против хорошего, ≥ **0.60**
  (оценка отражает тяжесть).
* **Правило:** если правила без модели дают чувствительность выше, чем заключение, **более
  чем на 0.10** (модель уровня записи «отменяет» находки правил в коме) → следующим
  инкрементом вводится запрет модели переводить в «норму» запись с тяжёлой находкой правил
  (подавление / вспышка-подавление / периодические разряды) с проверкой регрессий на NMT.
  Иначе конфигурация не меняется.

Описание: по больницам, по исходу, доля пограничных, какие находки дают «отклонения», у кого
заключение «норма».

## 5. Воспроизведение

```bash
PYTHONPATH=src python scripts/run_icare_eval.py docs/increment35_icare.jsonl --workers 4
PYTHONPATH=src python scripts/run_icare_eval.py --assess docs/increment35_icare.jsonl docs/increment35_assessment.json
```

## 6. Ограничения

Чувствительность здесь — к грубой патологии фона в коме, не к умеренным отклонениям рутинной
ЭЭГ (фокальное замедление, редкие разряды); это нижняя проверка: провал H1 значил бы, что
заключение на чужом приборе пропускает даже явную патологию. Меток ЭЭГ нет: «отклонения»
ожидаются по клинике. Больница C в открытую часть не входит.
