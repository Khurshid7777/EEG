Результаты: `docs/increment78_assessment.json`, сырьё `docs/increment78_events.jsonl`. Данные: 64 аномальные записи, 5192 аннотированных событий (3835 эпилептиформных), исключений нет.

## Решение по пре-регистрированному правилу

Правило требовало выполнения всех трёх условий; **H2 не выполнено** (+0.144 вместо +0.15 над базовой линией «случайный канал») → привязка события к области по сигналу в карту **не включается**. Критерий не пересматривался и не округлялся. Базовая линия области на этой части высока (0.694), потому что эксперты отмечали много каналов на событие (в среднем 12 из 19), и случайный электрод попадает «в нужную область» очень часто; полушарие (M3) и канал (M1) этой проблемой затронуты меньше.

## Что видно

* Определение **полушария по энергии второй производной** воспроизводится на независимой выборке: 0.875 (ДИ [0.806, 0.913]) на обучающей части и 0.792 на тестовой — устойчиво выше базовой линии 0.50.
* Для **замедления** вариант C не работает (M3 0.368, M2 ниже самой частой области); энергия второй производной — признак остроты, а не медленных волн. Любая привязка по сигналу — только для эпилептиформных событий.
* Эксперты размечают «где виден разряд», а не источник; результат относится к этой разметке (одна страна, один прибор, референт набора заменён общим средним).

## Последствия

Привязка по сигналу не вносится; события без каналов остаются «без привязки к каналам». Полушарие по варианту C подтверждено на двух частях одной базы (но каждый раз выбор варианта был связан с этими данными). Следующий шаг — независимая проверка на другом центре (NMT-4K после доступа) с заранее заданным решающим правилом по полушарию как основной метрике (отдельная пре-регистрация; не пересматривать критерии инкремента 78 ретроспективно).
