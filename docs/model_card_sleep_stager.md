# Карточка модели: стадирование сна NeuroLens (`sleep_stager_*`, `sleep_smoothing_aasm_v1`)

> Формат — карточка модели для технической документации и подготовки к регуляторной оценке
> (ТЗ §14–16). Метод — `src/neurolens/layer4_detect/sleep_staging.py`; проверки — пре-регистрации
> инкрементов 13, 14, 49, 50, 51, 52, 55 и отчёты к ним.

## 1. Сведения о модели

Четыре пути стадирования; путь выбирается по имеющимся электродам (`derivations()`), для каждого —
своя модель. Тип везде один: градиентный бустинг деревьев (5 классов W / N1 / N2 / N3 / REM) на
признаках 30-секундных эпох, исполнение numpy, формат JSON без исполняемого кода.

| Путь | Электроды | Модель (SHA-256, начало) | Включён |
|---|---|---|---|
| Средняя линия | Fpz-Cz, Pz-Oz, ЭОГ | `sleep_stager_v1` (`73785126…`) | да (инкремент 13) |
| Парасагиттальный | Fp2-C4, P4-O2, ЭОГ | `sleep_stager_clinical_v1` (`c3bfcabe…`) | да (инкремент 14) |
| **Стандартный монтаж ПСГ** | F4-C4, C4-O2 (левая сторона, если нет правой), ЭОГ | **`sleep_stager_aasm_v4`** (`3affd3b5…`) + **`sleep_smoothing_aasm_v1`** (`be614d1c…`) | **да** (инкременты 52, 55) |

Ранние версии монтажа AASM — `aasm_v1`, `_v2`, `_v3` (`fab0f2b3…`, `97d986b1…`, `8a7a55e0…`) —
**не включены** (раздел 6) и хранятся для воспроизводимости.

Общие параметры обучения: scikit-learn `HistGradientBoostingClassifier`, 200 итераций, ≤ 31 лист,
lr 0.1, class_weight balanced, random_state 0. Эпоха 30 с, частота модели 100 Гц. Признаки на эпоху:
спектральные (6 полос, относительные и логарифмические мощности, энтропия, SEF95), Hjorth, отношения
полос — для двух производных, три признака горизонтальной ЭОГ; нормировка внутри ночи (медиана / IQR,
эпохи с пропусками игнорируются) и контекст ±2 эпохи. Модель v4 дополнительно получает
ненормированные логарифмы мощности (общая, 0.5–2 Гц, 2–4 Гц) обеих производных: абсолютная
амплитуда, по которой AASM определяет N3.

Сглаживание (только путь AASM): алгоритм Витерби по вероятностям модели с матрицей переходов между
стадиями (по 416 ночам разработки) и весом 0.5. Период сна определяется двухпроходно; пробуждения
короче 2 ч (для остальных путей — 30 мин) склеиваются.

## 2. Назначение

* **Предназначение:** автоматическая гипнограмма и показатели сна (время в записи, сон, эффективность,
  латентности, доли стадий) в отчёте оффлайн-анализа ПСГ и длительной ЭЭГ взрослых — для просмотра
  специалистом. Режим A: обязательная проверка врачом.
* **Не предназначено для:** замены ручной разметки; диагностики нарушений сна (апноэ, бессонница,
  нарколепсия); оценки фрагментации сна (раздел 5); детей и новорождённых (стадирование отключено для
  возраста < 18 лет, у детей каппа 0.17, D83); записей короче 2 ч (`min_duration_h`); других монтажей.

## 4. Качество (каппа Коэна с экспертом, 5 классов)

| Модель | Проверка | Каппа |
|---|---|---|
| `sleep_stager_v1` | Sleep-EDF, 75 ночей, пре-регистрация | 0.71 |
| `clinical_v1` | CAP, 34 новых пациента | 0.71 |
| **`aasm_v4`** | **CinC 2018, 150 записей, пре-регистрация** | **0.619** (95% ДИ 0.596–0.639) |
| `aasm_v4` | исключение одного центра (разработка): ds007181 / BOAS / EESM19 / HMC | 0.61 / 0.54 / 0.67 / 0.61 |
| **`aasm_v4` + сглаживание** | **CinC 2018, 150 новых записей, парное** | **0.630** (прибавка +0.017, ДИ 0.012–0.022) |
| **`aasm_v4` + сглаживание** | **COVISLEEP (Nox A1, бессонница), 92 ночи, пре-регистрация, другой центр** | **0.635** (ДИ 0.602–0.666; без сглаживания 0.605, прибавка +0.031, ДИ 0.026–0.036) |

F1 по стадиям на CinC 2018 (v4 без сглаживания → со сглаживанием): W 0.76 → 0.77, N1 0.46 → 0.43,
N2 0.77 → 0.79, N3 0.72 → 0.73, REM 0.78 → 0.81. Узнавание N3: 79%.
Смен стадии на эпоху: 19.0% → 6.5%.

## 5. Ограничения и риски

* **N1** определяется ненадёжно (F1 ≈ 0.43), в тексте отчёта это сказано.
* **Граница N2/N3 зависит от центра** (D96): эксперты BOAS ставят N3 только при очень мощных медленных
  волнах (4.5% N3 против 13–20% у других); у BOAS каппа 0.54, с объединёнными N2+N3 — 0.70. Доля N3 в
  отчёте — оценка с межцентровой неопределённостью.
* **Сглаживание может скрывать фрагментацию сна** (кратковременные пробуждения, апноэ). Число смен
  стадии не мера фрагментации; оговорка включена в текст отчёта (RU/UZ).
* Три предыдущие версии монтажа AASM не прошли порог 0.60 (раздел 6). Результат v4 получен после
  исправления двух дефектов продукта и добавления абсолютной амплитуды; разработка и тест v4 — не на
  одном центре, и на втором независимом центре (COVISLEEP, 0.635, инкремент 56) качество подтвердилось, в том числе сглаживание.
* Пропуски сигнала (NaN): нормировка игнорирует такие эпохи; фильтрация идёт по непрерывным участкам
  (D94, D95). Полностью пропуск не нейтрален.
* COVISLEEP: N1 по-прежнему слаб (F1 0.22 — у людей с бессонницей много бодрствования и N1); каппа в подгруппе после long-COVID 0.654, без — 0.626.
* Проверено на лабораторной ПСГ взрослых; домашняя ПСГ без пары глазных электродов и записи
  с тяжёлой патологией сна не проверялись отдельно.
* Тест CinC 2018 — один глазной канал (E1-M2); при двух электродах (E1/E2) на разработке качество выше
  (HMC: 0.613 против 0.597).

## 7. Прослеживаемость

Модели заморожены по SHA-256 (`docs/regulatory/software_lifecycle.md` §3); изменение модели,
порога или правила — только через пре-регистрированную проверку (R14). Настройки —
`configs/sleep.yaml`; тесты — `tests/test_sleep.py`, `tests/test_ml_ictal_gaps.py`.
