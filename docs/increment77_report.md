# Инкремент 77: привязка события к каналам и областям по сигналу (NMT-Events, тест)

Пре-регистрация: `docs/preregistration_increment77.md` (до чтения сигналов). Код: `src/neurolens/layer3_features/event_localiser.py` (+ `tests/test_event_localiser.py`), `scripts/run_event_localisation.py`. Результаты: `docs/increment77_assessment.json`, сырьё `docs/increment77_events.jsonl`. Данные: 49 аномальных записей тестовой части, 4699 аннотированных событий (2910 эпилептиформных, 1789 замедление), исключений нет.

## Решения по пре-регистрированным правилам (вариант A)

* **H1** (M3 ≥ 0.75 и нижняя граница ДИ > 0.60): M3 = 0.671, ДИ [0.549, 0.826] — **не выполнена**.
* **H2** (M2 ≥ 0.60 и выше случайного канала на ≥ 0.15): M2 = 0.702, превышение 0.142 — **не выполнена** (порог 0.15 не достигнут на 0.008).
* **H3** (M1 ≥ 0.40 и ≥ 2× случайного канала): M1 = 0.595 против базовой линии 0.461; удвоение (0.92) недостижимо, так как базовая линия высока (эксперты отмечают в среднем 8.8 из 19 каналов) — **не выполнена**; это недочёт самого правила (раскрыт, не пересматривается).

Итог: привязка события к области по сигналу **не включается** в карту; события без каналов остаются «без привязки».

## Замечания

* Вариант **C** (энергия второй производной, острота) заметно лучше A: M1 0.673, M2 0.754 (+0.193 над случайным), M3 0.792. По пре-регистрации это чувствительность, а не выбор; решение по основному варианту не меняется. Так как C выбран постфактум по этим же данным, его эффект нельзя считать подтверждённым — нужна независимая проверка (инкремент 78: обучающая часть NMT-Events, которая не использовалась для локализации, затем NMT-4K).
* Замедление (описательно): M1/M2 близки к базовой линии (области почти всегда лобные: «самая частая область» даёт 0.982), полушарие у односторонних событий 0.59 (A) / 0.42 (B) — локализация медленных волн по пику не работает.
* Ограничения: эксперты размечали «где виден разряд», а не источник; референт набора заменён общим средним; одна страна и один прибор.
