# NeuroLens: что проверено и насколько — сводка для врача и регуляторной подготовки

> Состояние на 2026-10-17. Каждое число — из пре-регистрированной проверки на людях, не
> участвовавших в обучении (если не оговорено иное), со ссылкой на отчёт. Это **инженерная**
> валидация на открытых данных PhysioNet/Zenodo, а не клиническое испытание. Система —
> поддержка решений: каждое событие и каждая тревога требуют проверки врачом.

## 1. Что система делает по умолчанию

| Функция | Взрослые и дети (≥ 1.5 года) | Новорождённые (указан ПМВ) |
|---|---|---|
| Поиск приступов в записи (оффлайн) | обученная модель `ictal_gbm_offline_v2` | **пороговый детектор** (обученная модель хуже — инкремент 12) |
| Тревоги о приступах в мониторе | обученная модель `ictal_gbm_realtime_v2` | неонатальная модель `ictal_gbm_realtime_neo2` (**на другом центре — 10.8 ложных тревог/ч**, инкремент 28) |
| Эпилептический статус | ACNS 2021: ≥ 10 мин непрерывно или ≥ 20% любого часа | ACNS 2013: ≥ 50% любого часа |
| «Вспышка-подавление» | общий детектор | только при межвспышечном интервале длиннее нормы для ПМВ |
| Иктально-интериктальный континуум (IIC) | присваивается | не применяется (нет в неонатальной терминологии) |
| Стадирование сна (≥ 2 ч записи) | с центральной линией — `sleep_stager_v1`; клиническая цепочка без неё — `sleep_stager_clinical_v1` | **не выполняется** (модели проверены только у взрослых) |
| Разряды (спайки, острые волны) | эвристический детектор — **не прошёл проверку** (инкременты 15–16); метки — подсказки для просмотра, у каждой вероятность обученной модели (порядок просмотра) | эвристика без вероятности |
| Неправдоподобная амплитуда (< 0.5 или > 300 мкВ) | отчёт помечается, режим B закрыт, эскалация (ошибка единиц файла или крайнее подавление) | то же |
| < 4 скальповых ЭЭГ-каналов | анализ приступов **не выполняется**, отчёт и монитор прямо об этом сообщают, режим B закрыт | то же |

Переключатели — `configs/ml.yaml`, `configs/sleep.yaml`; каждое значение по умолчанию
выставлено кодом применения пре-регистрированного решения (`evaluation/prereg*.apply_decision`).

доля истинных событий среди детекций — ≈ 9% оффлайн, ≈ 16% в мониторе (калиброванная
уверенность это отражает).

**Вывод:** выявление приступов у новорождённых — около половины приступов; для
самостоятельного клинического применения у новорождённых недостаточно.

## 5. Разряды (интериктальные эпилептиформные)

Пре-регистрированная проверка (инкремент 15; NMT-Events, 168 новых людей: 37 записей с 2 190
разрядами и 119 нормальных записей, 49.8 ч; `docs/increment15_report.md`):

| Детектор | Найдено разрядов (95% ДИ) | Ложных/ч нормальной ЭЭГ |
|---|---|---|
| обученный (порог 0.95; **не включён** — критерии ≥ 0.50 и ≤ 22.5/ч не выполнены) | 0.46 (0.29–0.65) | 31.0 |
| эвристический, по умолчанию (используется) | 0.91 | 1 864 |
| эвристический, самый строгий | 0.03 | 35.4 |

Внешняя проверка различения (инкремент 16; 100 пациентов другого центра, у каждого — один острый
транзиент, отмеченный экспертом; диагноз по видео-ЭЭГ; `docs/increment16_report.md`):

| Метод | AUC: эпилептиформный против доброкачественного | Специфичность |
|---|---|---|
| обученная модель (вероятность — в отчёте у каждого кандидата) | **0.72** (0.62–0.82) | 1.00 при 0.95, но чувствительность 0.04 |
| эвристический детектор (формирует кандидатов) | 0.49 — случайный уровень | 0.13 |
| эксперты / 5 критериев IFCN (исходное исследование) | точность 0.92 / 0.91 | 0.96 (IFCN) |

**Вывод:** ни один детектор разрядов не пригоден для самостоятельного использования. Обученный
лучше эвристического во всех точках, но изолированные острые волны находит в 5% случаев, а
ложные метки сосредоточены в записях с артефактным/высокоамплитудным фоном. Метки «спайк» в
отчёте — только указания, где посмотреть; вероятность модели помогает упорядочить просмотр,
но низкая вероятность разряд не исключает.

## 6. Заключение «норма / отклонения» на рутинной ЭЭГ

Пре-регистрированная проверка (инкремент 17; NMT, оценочная часть авторов: 95 нормальных и 90
аномальных рутинных ЭЭГ, разметка неврологов; `docs/increment17_report.md`):

| Версия | Специфичность (95% ДИ) | Чувствительность (95% ДИ) |
|---|---|---|
| до инкремента 17 | 0.00 (0.00–0.04) — каждая нормальная запись «патологическая» | 1.00 |
| инкремент 17 (оценочная часть, 185 записей) | 0.59 (0.48–0.69) | 0.84 (0.75–0.91) |
| инкремент 17 на свежих 250 записях (повторение) | 0.55 (0.47–0.63) | 0.79 (0.70–0.87) |
| инкремент 18, свежие 250 записей | 0.64 (0.56–0.72) | 0.78 (0.69–0.86) |
| инкремент 19, повторение на ещё 250 свежих | 0.64 (0.56–0.72) | 0.75 (0.65–0.83) |
| инкремент 19 на свежих 345 (300 + 45 последних аномальных) | 0.68 (0.63–0.74) | 0.60 (0.44–0.74) |
| инкремент 20, те же 345 | 0.73 (0.68–0.78) | 0.56 (0.40–0.70) |
| правила инкремента 20 на оценочной части (185; второе использование) | 0.77 (0.67–0.85) | 0.79 (0.69–0.87) |
| модель уровня записи v1, один порог (инкремент 22, пре-регистрация, оценочная часть) | 0.76 (0.66–0.84) | 0.87 (0.78–0.93) |
| **текущая — v2 без абсолютной амплитуды, пороги по возрасту** (инкременты 22b–25, post-hoc) | **0.79** | **0.80** |

Устойчивость текущего заключения (оценочная часть): две половины одной записи — пограничная зона
вокруг порога у 29% записей, вне неё вердикты половин расходятся в 8% (инкременты 23, 26);
256 Гц / без A1-A2 / без Fz-Cz-Pz — вердикт совпадает в 94–96%; усиление ×1.4 — специфичность
0.73, совпадение 95% (v1 давал 0.55; инкремент 25); возраст не указан — вариант без возраста
(0.77 / 0.83, инкремент 24). Модель применяется только к рутинным записям (< 45 мин); у детей
2–11 лет пороги по возрасту подняли специфичность с 0.28 до 0.72 ценой чувствительности.

**Вывод:** уровень скрининга с обязательным просмотром. ~1 из 5 нормальных записей получает
«признаки отклонений»; около трети заключений — пограничные и прямо отданы на решение врача; в аномальных, названных «без явной патологии», заключение всегда перечисляет
сомнительные находки для просмотра. Автономное заключение (режим B) на рутинной ЭЭГ клинически не
рекомендуется. Периодические разряды, похожие на ЭКГ (сердечная частота, почти идеальная регулярность) или
движения глаз (максимум Fp/F7/F8), помечаются гипотезой артефакта и идут как «сомнительно»
(инкремент 18; частота сердца — по возрасту, инкремент 20). События обученной модели приступов на
рутинной ЭЭГ — кандидаты для просмотра: модель проверена только на длительном мониторинге
(инкремент 20; «судорожная активность» в критических находках нормальных отчётов 87% → 0%).

## 7. Что НЕ проверено

* Записи ОРИТ с седацией, гипотермией, ЭКМО; приборы и частоты дискретизации вне
  использованных баз; монтажи вне 10-20 и биполярных цепочек CAP.
* Дети младше 1.5 лет (кроме новорождённых), дети для стадирования сна.
* Периодические паттерны ACNS, асимметрии — по отдельности не проверены на
  размеченных реальных данных (в открытых базах нет такой разметки); на рутинной ЭЭГ измерена
  только частота их ложных срабатываний (§6). Разряды проверены и не прошли (§5).
* Языковая часть отчёта (LLM) — заземлена на события и проверяется валидатором ссылок, но
  клиническое качество текста не оценивалось.

## 8. Как воспроизвести

Все данные открытые (PhysioNet: CHB-MIT, Siena, Sleep-EDF, CAP; Zenodo: Helsinki neonatal, NMT-Events, IFCN IED criteria, NMT);
загрузка с проверкой SHA-256/MD5 (`neurolens physionet fetch`, `neurolens sleep fetch`, `neurolens ied fetch` — CRC-32);
каждое число воспроизводится командой из соответствующей пре-регистрации
(`docs/preregistration_increment*.md`), модели заморожены по SHA-256.
