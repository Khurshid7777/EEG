# Пре-регистрация, инкремент 38: детекторы разрядов на данных другой страны (vepiset, Пекин)

> Зафиксировано до прогона детекторов. Открыт только формат одной записи (DA001003: ключи
> `eeg_data` 29 × 594 000 и `events`, единицы — вольты, медиана СКО 56 мкВ после ×10⁶;
> отмеченных разрядов в ней нет) и проверен путь обработки на ней; оценки детекторов не
> просматривались.

## 1. Зачем

Детекторы разрядов проверялись на NMT-Events (Пакистан, инкремент 15: обученный — 0.46 при
31 ложной/ч) и на 100 отмеченных транзиентах IFCN (инкремент 16, AUC 0.72). Обученная модель
не включена как детектор, но её вероятность показывается у кандидатов как довод
(`annotate_candidates: true`). Независимого набора с полной разметкой разрядов на непрерывной
ЭЭГ другой страны не было.

## 2. Данные

vepiset (Lin et al., Scientific Data 2025; figshare 10.6084/m9.figshare.28069568.v2, CC BY):
84 пациента Пекинского союзного медицинского колледжа (Китай), по 20 мин непрерывной рутинной
ЭЭГ, 500 Гц, 19 электродов 10-20 (+ A1/A2, PG1/PG2, ЭКГ, ЭМГ), отметки разрядов (`!` — момент
разряда, `!start`/`!end` — серия), бодрствование/сон. По авторам — 2 516 эпох по 4 с с
разрядами и 22 933 без. Часть записей без отмеченных разрядов (видно на DA001003).

## 3. Прогон (`scripts/run_vepiset_eval.py`, `evaluation/vepiset_eval.py`, код этого коммита)

Как в инкременте 15: фильтры, усреднённый референт, 19 электродов + ЭКГ; замороженная модель
`ied_gbm_v1` (sha256 из `docs/preregistration_increment15_frozen.json`, порог 0.95) и
эвристический `SpikeDetector` по сетке порогов остроты. Ничего не настраивается.

* **Эталон:** отметка `!` в t → событие [t − 0.15, t + 0.15] с; серия — её интервал; совпадение
  с допуском 0.25 с (как в инкременте 15).
* **Ложные/ч** — все обнаружения в записях **без отмеченных разрядов** (у пациентов с
  эпилепсией; полнота разметки — по авторам).
* **Эпохи:** 4-с эпохи как у авторов (положительная — отметка внутри эпохи дальше 0.1 с от
  края или перекрытие с серией); оценка эпохи — максимум вероятности окон модели в ней;
  для эвристики — наибольший порог остроты, при котором в эпохе есть обнаружение.
* Нечитаемые записи исключаются и публикуются числом.

## 4. Гипотезы и правило решения (`evaluation/prereg38.py`)

* **H1** — AUC вероятности модели на эпохах ≥ **0.80**.
* **H2** — модель различает лучше эвристики: нижняя граница 95% бутстреп-интервала (по
  пациентам) разности AUC > 0.
* **Правило:** если AUC модели < **0.70**, её вероятность перестаёт показываться у кандидатов
  как довод (`annotate_candidates: false`); иначе конфигурация не меняется. Включение модели
  как детектора по одному набору не рассматривается.

Описание: чувствительность и ложные/ч при пороге 0.95 и у эвристики по умолчанию (z = 6)
против NMT-Events; AUC отдельно в бодрствовании и сне.

## 5. Воспроизведение

```bash
PYTHONPATH=src python scripts/run_vepiset_eval.py docs/increment38_vepiset.jsonl --workers 3
PYTHONPATH=src python scripts/run_vepiset_eval.py --assess docs/increment38_vepiset.jsonl docs/increment38_assessment.json
```

## 6. Ограничения

Разметка — по авторам, число разметчиков и согласие не проверялись; отметка `!` — момент
без длительности; эпохи с разрядами взяты как у авторов. Все пациенты — с эпилепсией: ложные/ч
в записях без разрядов — не то же, что у здоровых.
