## Проверка на удержанных здоровых (65 записей: ds004504 контроли 29 + eegmat фон 36)

Доля записей вне пределов по парам: C3–C4 0.092, F3–F4 0.062, F7–F8 0.077, O1–O2 0.046, P3–P4 0.031, **T3–T4 0.123**, T5–T6 0.062; среднее **0.070**.

* **H1** (среднее ≤ 0.10, максимум ≤ 0.20): **подтверждена**.
* **H2** (хотя бы одна пара вне пределов ≤ 0.30, описательно): **0.354** (ds004504 0.31, eegmat 0.39) — не выполнена. Для семи пар при 5% на пару ожидалось ≈ 0.30, что и наблюдается; вывод: флаг по принципу «любая пара» создаёт слишком много ложных меток.
* Возраст (ранговая корреляция Спирмена |AI| с возрастом, ds003775): от −0.14 (O1–O2) до +0.11 (F3–F4) — слабая; возрастные пределы не нужны.

## Вывод

Пределы по отдельной паре переносятся между тремя центрами (Осло, Иоаннина, Харьков; разные приборы и референты). В продукте асимметрия показывается числом с нормативным коридором по паре. Метка «патологическая асимметрия» по одной паре не используется; для заключения требуются согласованные признаки (две соседние пары, выход за пределы с запасом, согласие с детекторами) — это проверяется на метках очага (фаза B3, инкремент 75: CHB-MIT, Siena). Клиническая чувствительность пределов пока не измерялась.

## Ограничения

Здоровые добровольцы; пределы выведены на одном центре обучения (BioSemi, 4 мин закрытых глаз) и проверены на двух других; записи eegmat очищены автором; 95% интервалы для долей на 65 записях широкие (например, при 0.123 ≈ ±0.08).
