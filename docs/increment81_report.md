# Инкремент 81: нужны ли возрастные нормы межполушарной асимметрии — нет

Пре-регистрация: `docs/preregistration_increment81.md` (до расчёта; раскрыто, что описательные корреляции были показаны в инкременте 74). Код: `scripts/run_asymmetry_age.py`. Результат: `docs/increment81_assessment.json`. Новые сигналы не загружались.

**Ни одна проверка не значима после поправки Холма** (наименьшая p = 0.0126 при пороге 0.0036). По пре-регистрированному правилу возрастные нормы **не нужны**; остаются объединённые пределы инкремента 74. Шаг 2 (квантильная регрессия) не запускался.

## Описательно (удержанные здоровые)

Доля записей вне объединённых пределов: ds004504 (старше, 57–78 лет) — от 0.03 до 0.10 по парам, максимум 0.10 (C3–C4, T5–T6); eegmat (моложе, 16–26) — от 0.00 до 0.19 (T3–T4: 0.19 при n = 36, то есть 7 записей). У старшей группы доля ложных меток **не выше**, чем у младшей.

## Замечания

* Номинальные (без поправки) связи с возрастом есть у O1–O2 (ρ = −0.25, p = 0.013) и C3–C4 (ρ = +0.24, p = 0.019), но при 14 проверках и 99 записях они не выдерживают поправку; мощность невелика для эффектов |ρ| < 0.3, отсутствие зависимости не доказано.
* Выше T3–T4 доля ложных меток в eegmat (0.19) связана не с возрастом, а, вероятно, с набором/прибором (7 из 36 записей); общий вывод инкремента 74 (пределы переносимы: среднее 0.07) не меняется.

## Вывод

Возрастные пределы асимметрии не вводятся; в карте используются объединённые нормативные пределы (`configs/regional_norms_v1.json`). При появлении более широкой выборки (NMT-4K после доступа, дети и пожилые) вопрос можно открыть заново отдельной пре-регистрацией.
