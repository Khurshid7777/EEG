## I-CARE повторно (описание; данные видены в инкрементах 35–36)

Тот же отбор, 606 пациентов (1 исключён, как в инкременте 35), рабочая конфигурация
(запрет инкремента 36 + критерий ЗДР):

| | Инкремент 35 | Инкремент 37 |
|---|---|---|
| Чувствительность заключения | 0.307 | **0.645** |
| Чувствительность правил | 0.781 | 0.792 |
| ЗДР «найден» у пациентов в коме | 69% | 54% |
| AUC оценки, плохой против хорошего исхода | 0.39 | 0.39 |

* Рост заключения почти целиком — от запрета инкремента 36 (201 из 205 новых «отклонений» —
  вспышка-подавление); критерий ЗДР добавил немного (пост-хок оценка запрета без него: 0.639).
* По больницам: A 0.71, B 0.75, D 0.62, E 0.41, F 0.52.
* Правила по-прежнему оставляют «норму» у 126 (21%), у 68 из них ЗДР остаётся — пик 4–13 Гц,
  который сильнее сзади: критерий отсекает лобную альфа-/тета-кому, но не седацию с
  сохранённым задним градиентом. Реактивность (второй признак ЗДР) без меток проб не проверить.
* Оценка модели по-прежнему обратна тяжести (AUC 0.39): модель обучена на бодрствовании.

## Вывод

Определение ЗДР стало ближе к клиническому без потерь на рутинной ЭЭГ. Для реанимации это
не решение: заключение рутинной ЭЭГ остаётся непригодным для комы (0.645 < 0.80), записи
реанимации — в монитор.
