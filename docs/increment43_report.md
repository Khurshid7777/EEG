# Инкремент 43: сравнение по участкам бодрствования (v2) — чувствительнее, но не прошло по специфичности

Пре-регистрация: `docs/preregistration_increment43.md` (коммит 97f883e). Пределы зафиксированы по
части разработки ds005385 до открытия проверочной (коммит 8e8a85c, `docs/increment43_limits.json`).
Скрипт: `scripts/run_ds005385_serial.py`; построчно — `docs/increment43_ds005385_dev.jsonl`,
`docs/increment43_ds005385_test.jsonl`; сводка — `docs/increment43_assess.json`. Решение — D77.

## Данные

OpenNeuro ds005385 (Dortmund Vital Study): здоровые 20–70 лет, по 3 мин с закрытыми и открытыми
глазами до и после 2 часов заданий. Выборки по 100 человек (seed 43): разработка — 200 записей,
проверка — 322 записи. Повтор через 5 лет есть у 22 человек проверочной части. Ошибок чтения нет.
Три обрыва загрузки в части разработки (curl 18/52) пересчитаны один раз.

## Проверка (100 человек)

| гипотеза | результат | правило |
|---|---|---|
| H1: стабильные (до/после заданий) хотя бы с одной отметкой, v2 | **18 из 100 = 0.18** (0.11–0.27) | ≤ 0.15 — **не выполнено** |
| H2: открывание глаз отмечено, v2 | **50 из 100 = 0.50** (0.40–0.60) | ≥ 0.40 — выполнено |
| H3: v2 чаще v1 | v2 — 50, v1 — 18; только v2 — 32, только v1 — 0; p = 2·10⁻¹⁰ (Мак-Немар) | выполнено |

Вторично:
* v1 с пределами этой же разработки: 15 из 100 стабильных с отметкой.
* **Пределы продукта** (ds004148, инкремент 42) на этих людях: **17 из 100**. В инкременте 42 было
  1 из 30.
* **5 лет** (22 человека, v2): отметки у 3. Средние изменения близки к нулю: основной ритм
  −0.03 Гц, доли ±2%.

**Решение по пре-регистрации («H1 не выполнена для v2»):** v2 в продукт не включается, v1
остаётся с прежними пределами. Признаки `alert_rel_*` остаются в сводке записи (вычисляются, но в
сравнении продукта не используются).

## Разбор после проверки (не гипотеза)

Лишние отметки у стабильных — в основном **основной ритм** (10 из 100 и в v1, и в v2: эта часть у
них общая). Остальные величины v2 дают 1–7%.

Основной ритм у этих 10 человек «скачет» на 1.2–5 Гц: например, 11.25 → 6.0, 11.0 → 8.25,
8.25 → 5.75 Гц. После двух часов заданий в 3-минутной записи с закрытыми глазами вершина спектра
всей записи уходит в тету дремоты. Это слабое место всего сравнения, а не только v2.

Следующий шаг — измерять основной ритм на тех же бодрых эпохах, что и доли v2. В инкременте 43
его выбирали по ds004148 и выбрали неудачно: вариант «alert» из инкремента 20 менее устойчив.
Нужна новая пре-регистрация.

Практический вывод для продукта: на людях 20–70 лет пределы v1 дают хотя бы одну отметку
примерно у 15–17% стабильных здоровых, а не у 3%, как на ds004148. Это теперь указано в тексте
сравнения. Отдельная отметка по основному ритму без изменения долей — повод посмотреть запись на
сонливость, а не вывод об изменении.
