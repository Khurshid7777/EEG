# Клиническая оценка — сводка данных, пробелы и план исследования (черновик)

> Подробные числа с доверительными интервалами — `docs/performance_summary.md` и отчёты
> инкрементов. Здесь — структура клинической оценки по MDCG 2020-1 для ПО: научная
> обоснованность, техническая (аналитическая) работоспособность, клиническая работоспособность.

## 1. Научная обоснованность (valid clinical association)

Выходы системы опираются на признанные клинические определения:
* ACNS 2021 — терминология критической ЭЭГ: статус, вспышка-подавление, IIC, задний доминирующий
  ритм;
* ACNS 2013 — неонатальная ЭЭГ;
* AASM — стадии сна;
* IFCN — критерии разрядов.

Связь этих признаков с клиническими состояниями установлена литературой и в задачу проекта не
входит.

## 2. Техническая работоспособность

* **Чтение форматов:** совпадение с независимыми реализациями — MNE (Nihon Kohden, Persyst), neo
  (Micromed); реальные записи BrainVision, EDF разных приборов (D74, D79–D81).
* **Устойчивость к записи:**
  - частота дискретизации 256 Гц, отсутствие A1/A2 или средней линии — вердикт совпадает в
    94–96%;
  - ошибка усиления ±30–40% → специфичность ±0.06;
  - вердикты двух половин записи совпадают вне пограничной зоны в 92%.
* **Измерения:**
  - реактивность альфа-ритма у здоровых — 87% реактивны (D75);
  - пределы изменчивости при повторной записи (D76–D78).
* **Живой поток:** результаты совпадают с воспроизведением файла (D82).

## 4. Пробелы и план клинического исследования

Открытые данные не заменяют данных целевой популяции. Нет проверки на:
* приборах и в центрах предполагаемого применения;
* реанимации с седацией;
* периодических паттернах ACNS с экспертной разметкой;
* влиянии на работу врача (время, точность).

**Предлагаемый дизайн** (для обсуждения с этическим комитетом и консультантом):

1. **Ретроспективная многоцентровая часть.**
   * 2–3 целевых центра. Последовательные рутинные ЭЭГ: не менее 300, с долей патологии, близкой
     к клинической. Длительные мониторинги с приступами: не менее 50 пациентов, не менее 150
     приступов.
   * Эталон — независимая разметка трёх нейрофизиологов, не видевших результатов системы.
     Расхождения решаются консенсусом.
   * Первичные конечные точки, пороги которых фиксируются до анализа:
     - для заключения — чувствительность и специфичность против эталона;
     - для монитора — чувствительность к приступам по пациентам и ложные тревоги в час.
2. **Исследование с чтецами (reader study).** Врачи читают записи с системой и без неё
   (перекрёстный дизайн, отмывочный период). Конечные точки: точность, время на запись,
   согласованность.
3. **Проспективное наблюдательное (PMCF).** Система работает в фоне. Исправления врачей
   собираются через `/feedback`, анализируются ежеквартально, калибровка уверенности обновляется.
   Изменения моделей — только через пре-регистрированные проверки.

Готовые инструменты:
* регламенты записи и экспорта с автоматической проверкой (`file-check`), что важно для
  однородности данных центров;
* обезличивание и журнал аудита;
* сбор исправлений врачей;
* скрипты пре-регистрированной оценки, которые переносятся на новые данные.
