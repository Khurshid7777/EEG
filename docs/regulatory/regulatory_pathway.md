# Путь регистрации — черновик для обсуждения с регуляторным консультантом

> Классы и процедуры указаны по общедоступным правилам. Окончательная классификация зависит от
> утверждённого назначения (`intended_use.md`) и подтверждается уполномоченным органом или
> консультантом. Пункты «уточнить» не проверены.

## 1. Европейский союз (MDR 2017/745)

* **Правило 11** (прил. VIII). ПО, которое даёт информацию для решений с диагностической или
  терапевтической целью, относится минимум к **классу IIa**.
  - Класс IIb — если решения могут вызвать серьёзное ухудшение состояния или хирургическое
    вмешательство.
  - Класс III — если решения могут вызвать смерть или необратимое ухудшение.
* Для NeuroLens:
  - Анализ записи и заключение с обязательным просмотром врачом — вероятно, **IIa**.
  - Тревоги о приступах в ОРИТ и ОРИТН — довод в пользу **IIb**: пропуск эпилептического
    статуса ведёт к серьёзному ухудшению. Есть вариант: сузить назначение монитора до
    «вспомогательного указания на участки для просмотра без функции тревоги».
* Нужны:
  - уполномоченный орган (Notified Body);
  - система менеджмента качества по ISO 13485;
  - техническая документация (прил. II–III);
  - клиническая оценка (ст. 61) и план пост-маркетингового наблюдения (PMS/PMCF).
* MDCG 2019-11 — квалификация и классификация ПО; MDCG 2020-1 — клиническая оценка ПО.

## 2. США (FDA)

* Программы автоматического выявления событий ЭЭГ регулируются как изделия класса II
  (21 CFR 882.1400, электроэнцефалограф). Обычно — уведомление **510(k)** с предикатом.
  Предикаты — зарегистрированные программы обнаружения приступов и спайков (уточнить по базе
  510(k): коды продукта, номера, назначение).
* Для изменений моделей после выпуска — план заранее определённых изменений (PCCP) для
  ПО с машинным обучением. Механизм пре-регистрации проекта близок к нему по духу.

## 3. ЕАЭС / Российская Федерация

* Регистрация медицинских изделий по правилам ЕАЭС или национальным правилам. ПО, являющееся
  медицинским изделием, классифицируется по риску (1, 2а, 2б, 3); уточнить действующие
  номенклатуру и приказ о классификации.
* Обычно требуются технические испытания, токсикологические — не применимо, клинические
  испытания (для ПО — часто в форме анализа данных) и экспертиза качества.

## 4. Республика Узбекистан

* Государственная регистрация медицинских изделий уполномоченным органом системы
  здравоохранения. Уточнить у консультанта:
  - действующий порядок и признание регистраций ЕС или ЕАЭС;
  - требования к ПО и к языку документации (протокол уже двуязычный RU/UZ);
  - требования к локальным клиническим данным.
