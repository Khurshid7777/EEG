# Техническая документация NeuroLens — черновик пути к сертификации

> Черновик производителя (2026-10-26), собранный из доказательной базы проекта: пре-регистрации,
> отчёты, решения D1–D83, тесты. Это **не** регистрационное досье. Перед подачей документы
> проверяют регуляторный консультант и клиницисты. Нормативные ссылки и классы указаны по
> общедоступным правилам и требуют подтверждения для конкретной юрисдикции и версии продукта.

| Документ | Что содержит | Стандарт / правило |
|---|---|---|
| [`intended_use.md`](intended_use.md) | назначение, пользователи, популяции, условия, противопоказания и ограничения | MDR прил. II §1.1; IEC 62366-1 |
| [`regulatory_pathway.md`](regulatory_pathway.md) | класс риска и путь регистрации (ЕС, США, ЕАЭС/РФ, Узбекистан) | MDR прил. VIII, правило 11 |
| [`risk_management.md`](risk_management.md) | анализ опасностей, меры контроля со ссылками на код и проверки, остаточный риск | ISO 14971 |
| [`software_lifecycle.md`](software_lifecycle.md) | класс безопасности ПО, SOUP, управление конфигурацией моделей, прослеживаемость | IEC 62304 |
| [`clinical_evaluation.md`](clinical_evaluation.md) | сводка клинических данных, пробелы, план клинического исследования | MDR ст. 61, прил. XIV; MDCG 2020-1 |

Источник чисел — `docs/performance_summary.md` и отчёты `docs/increment*_report.md`. Каждое число
воспроизводится командой из соответствующей пре-регистрации.
