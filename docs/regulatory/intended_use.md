# Назначение (Intended Use) — черновик

## 1. Назначение

NeuroLens — программное обеспечение для поддержки принятия решений при анализе ЭЭГ. Оно
анализирует цифровую запись ЭЭГ и формирует для врача:

* разметку событий — кандидаты приступов, разрядов, периодических паттернов, вспышки-подавления;
* количественное описание фона, функциональных проб и сна (у взрослых);
* проект протокола на русском и узбекском языках;
* при мониторинге — тревоги о возможных приступах.

**Результаты не являются диагнозом.** Каждое событие, тревога и заключение проверяются
квалифицированным врачом (нейрофизиологом, неврологом, реаниматологом) по исходной записи. Решение
о диагнозе и лечении принимает врач.

## 2. Пользователи

Врачи функциональной диагностики и нейрофизиологи, неврологи, реаниматологи; технический персонал
ЭЭГ — только для приёма записи (проверка файла по регламенту) и запуска анализа.

## 3. Популяции и условия применения

| Функция | Популяция | Условия | Основание |
|---|---|---|---|
| Поиск приступов, офлайн и монитор | взрослые и дети ≥ 1.5 года | длительный мониторинг, эпилептологический стационар | инкременты 11, 39 |
| Поиск приступов у новорождённых | доношенные новорождённые (указан ПМВ) | ОРИТН | инкремент 12: найдено около половины приступов; **только вспомогательно** |
| Тревога о фоне у новорождённых | доношенные новорождённые с ГИЭ | ОРИТН | инкремент 28 |
| Заключение «норма / отклонения» | ≥ 2 лет, рутинная ЭЭГ < 45 мин | амбулаторно | инкременты 17–37: скрининг с обязательным просмотром |
| Стадирование сна | **только взрослые ≥ 18 лет**, запись ≥ 2 ч | ПСГ, длительная ЭЭГ | инкременты 13–14; у детей не прошло (D83) |
| Функциональные пробы, сравнение с прошлой ЭЭГ | взрослые и дети | рутинная ЭЭГ | D75, D76–D77: описательно |

## 4. Входные данные

Цифровая ЭЭГ по схеме 10-20 (не менее 4 скальповых каналов для любого анализа, рекомендуется 19),
≥ 100 Гц (рекомендуется ≥ 200), в мкВ.

Форматы: EDF/EDF+/BDF, BrainVision, Nihon Kohden, Micromed, Persyst, EEGLAB, WFDB; поток LSL.

Требования к записи — `docs/recording_regulation.md`; их проверяет `file-check` до анализа.

Изображения бумажной ЭЭГ допускаются только по `docs/scanning_regulation.md` и только в режиме
просмотра врачом.

## 5. Противопоказания и ограничения применения

* Не применяется как единственное основание диагноза эпилепсии, смерти мозга, прекращения
  лечения или прогноза исхода комы.
* **Детектор разрядов не прошёл проверку как самостоятельный** (инкременты 15, 16, 38): метки
  разрядов — только указание, где смотреть.
* Заключение рутинной ЭЭГ не предназначено для реанимации и комы (инкремент 35).
* Не проверено:
  - ОРИТ с седацией, гипотермией, ЭКМО;
  - дети младше 1.5 года (кроме новорождённых);
  - недоношенные;
  - монтажи вне 10-20;
  - периодические паттерны ACNS на размеченных данных.
* Режим B («автономное заключение») закрыт автоматическими условиями. Для рутинной ЭЭГ клинически
  не рекомендуется.

## 6. Принцип работы (кратко)

Шесть слоёв: чтение и проверка записи → предобработка и качество → признаки → детекторы
(правила и замороженные обученные модели) → причинный граф и правила ACNS → заземлённый текст
отчёта. Каждое утверждение отчёта ссылается на событие или признак (валидатор заземления).
Пороги и модели меняются только кодом применения пре-регистрированного решения.
