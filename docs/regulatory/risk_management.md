# Управление рисками (ISO 14971) — черновик анализа опасностей

> Вероятность (В) и тяжесть (Т) — качественные, по шкале 1–5. Оценки вероятности опираются на
> измерения из проверок проекта, где они есть. Приемлемость остаточного риска окончательно
> оценивают клиницисты в рамках СМК.

## 2. Итог

Самые значимые остаточные риски — R1 (пропуск приступа), R3 (ложное «норма»), R9 (неверное
понимание меток разрядов). Все три сводятся одной мерой: система — **поддержка решений с
обязательным просмотром**, режим B для рутинной ЭЭГ клинически не рекомендуется. Для снижения R1
и R3 нужно клиническое исследование в целевых центрах (`clinical_evaluation.md` §4). Для R9 —
обучение пользователей и исследование удобства (IEC 62366-1).
