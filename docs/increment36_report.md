* Потеря специфичности 0.00 ≤ 0.02 → **запрет сохраняется** (`record_model_cannot_clear:

## Что это значит

На рутинной ЭЭГ поведение не меняется; меняется только запись с подавленным фоном: на I-CARE
(пост-хок, те же данные, по которым запрет выбран) чувствительность 0.307 → 0.639, у 140
здоровых взрослых и 95 норм NMT — без новых «отклонений». Независимой проверки на записях
реанимации нет, и даже с запретом чувствительность в коме ниже 0.80: заключение рутинной ЭЭГ
к реанимации не применяется.
