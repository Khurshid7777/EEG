# Технический регламент сканирования бумажной ЭЭГ для расшифровки

> Версия 1 (инкремент 34). Регламент задаёт, каким должно быть изображение листа бумажной ЭЭГ,
> чтобы сигнал можно было восстановить без потери диагностически значимой информации. Каждое
> требование проверяется автоматически: `neurolens scan-check СКАН.png ФОРМА.json`
> (`src/neurolens/layer1_ingest/scan_check.py`). Лист с хотя бы одним «отклонено»
> пересканируется.
>
> **Состояние:** модуля расшифровки кривых с изображения в проекте пока нет; регламент и
> проверка — входные условия для него. Любой сигнал, оцифрованный с изображения
> (`provenance.digitized = true`), **никогда** не получает автономного заключения (режим B
> закрыт) — только просмотр врачом, пока точность расшифровки не проверена на эталоне.

## 1. Почему это важно

На бумаге время задаётся скоростью ленты (мм/с), амплитуда — чувствительностью (мкВ/мм). После
сканирования каждый пиксель — это доля миллиметра, т. е. отрезок времени и ступень амплитуды.
Слишком грубое разрешение срезает спайки (20–70 мс) и бета-активность; перекос листа искажает
временную ось; сжатие с потерями (JPEG) размывает тонкие линии и меняет их амплитуду; фото
телефоном добавляет перспективу — расстояния на листе перестают быть пропорциональны времени.

## 2. Форма, заполняемая на каждый лист (обязательно)

Записывается техником при сканировании, файл JSON рядом с изображением (пример —
`examples/scan_form_example.json`):

| Поле | Что указать | Обязательность |
|---|---|---|
| `paper_speed_mm_s` | скорость ленты, как напечатано (15 / 30 / 60 мм/с) | обязательно |
| `sensitivity_uv_per_mm` | чувствительность (напр. 7 или 10 мкВ/мм); если разная по каналам — сканировать по разделам с одной | обязательно |
| `channel_labels` | подписи отведений **сверху вниз**, как на листе («Fp1-F3», …) | обязательно, ≥ 4 |
| `montage` | монтаж как напечатан (продольный биполярный, референтный A1A2, …) | обязательно |
| `calibration_pulse_uv` | амплитуда калибровочного прямоугольного импульса на листе | обязательно |
| `highpass_hz`, `lowpass_hz`, `notch_hz` | фильтры записи | желательно |
| `page_index`, `n_pages` | номер листа и общее число | обязательно |
| `page_overlap_s` | перекрытие соседних листов, с | если листов > 1 |
| `scanner` | `flatbed` / `sheetfed` / `camera` | обязательно |

## 3. Требования к изображению

| № | Требование | Порог | Проверка |
|---|---|---|---|
| 3.1 | Устройство | планшетный или протяжный сканер; **фото камерой/телефоном не допускается** | `scanner` |
| 3.2 | Формат файла | **PNG или TIFF без сжатия с потерями**; JPEG/HEIC/PDF-скриншот не допускаются | `format` |
| 3.3 | Цвет | 24-бит цвет (кривые разных цветов) или 8-бит оттенки серого; **не 1-бит**, не палитра | `colour_depth` |
| 3.4 | Разрешение | **≥ 300 dpi, рекомендуется 600 dpi**, записано в метаданные файла | `dpi` |
| 3.5 | Разрешение по времени | ≤ **4 мс на пиксель** (≥ 250 отсчётов/с эквивалента) | `time_resolution` |
| 3.6 | Разрешение по амплитуде | ≤ **2 мкВ на пиксель** | `amplitude_resolution` |
| 3.7 | Перекос | **≤ 0.5°**; лист прижат крышкой, край по направляющей | `skew` |
| 3.8 | Экспозиция | кривые видны, фон не залит (доля тёмных пикселей 0.3–40%) | `exposure` |
| 3.9 | Заливки | без крупных чёрных областей (тени, сгибы, штампы поверх кривых) | `black_clipping` (предупреждение) |
| 3.10 | Поля | лист целиком, кривые не обрезаны краем изображения | `margins` (предупреждение) |
| 3.11 | Калибровка | калибровочный импульс попадает на скан каждого листа (или первого листа серии с той же чувствительностью) | `calibration_pulse` |

Минимальное разрешение зависит от скорости ленты (требование 3.5):
**dpi ≥ 25.4 × 1000 / (4 мс × скорость, мм/с)**, но не ниже 300.

| Скорость ленты | Нужно для 4 мс/пикс. | Минимум регламента | Рекомендуется | Предельная частота при 600 dpi |
|---|---|---|---|---|
| 15 мм/с | 424 dpi | **600 dpi** | 600–1200 dpi | ~177 Гц |
| 30 мм/с | 212 dpi | 300 dpi | 600 dpi | ~354 Гц |
| 60 мм/с | 106 dpi | 300 dpi | 600 dpi | ~709 Гц |

(«Предельная частота» — геометрический предел пикселя; реальный предел задаёт толщина линии
пера и фильтр записи.)

## 4. Порядок сканирования

1. Проверить лист: без сгибов и надрывов; разгладить, не гладить утюгом термобумагу.
2. Сканер: режим «фото/документ без улучшений» — **выключить** автоконтраст, повышение резкости,
   удаление фона, «удаление линий», автообрезку и сжатие.
3. Положить лист по направляющей, прижать крышкой; лента длиннее стекла — сканировать
   частями с перекрытием ≥ 2 с записи и указать перекрытие в форме.
4. Разрешение — по таблице §3 (по умолчанию 600 dpi), цвет 24 бит, формат PNG/TIFF.
5. Имя файла: `<пациент-ID>_<дата>_<лист>-<из>.png`; форма — то же имя `.json`.
6. Запустить `neurolens scan-check` для каждого листа; при «ОТКЛОНЁН» — устранить причину,
   пересканировать.
7. Хранить оригинал бумаги до подтверждения расшифровки.

## 5. Что запрещено

* Фотографировать лист телефоном/камерой, в том числе «с ровного угла».
* Сохранять в JPEG или пересохранять PNG из JPEG.
* Обрезать поля и подписи отведений, закрывать кривые подписями/штампами.
* Масштабировать изображение после сканирования (меняет dpi без новой информации).
* Сканировать листы с разной чувствительностью как один файл без раздела в форме.

## 6. Что делает система с оцифрованным сигналом

* Сигнал с изображения помечается `provenance.digitized = true`.
* Режим B (автономное заключение) **закрыт** с причиной «сигнал оцифрован с изображения —
  только просмотр врачом»; критические находки по-прежнему сообщаются.
* Масштаб амплитуды проверяется по калибровочному импульсу, время — по скорости ленты из формы.

## 7. Ограничения регламента

* Пороги (4 мс/пикс., 2 мкВ/пикс., 0.5°) выбраны из физики записи (длительность спайка
  20–70 мс, амплитуды фона десятки мкВ) и стандартной практики сканирования документов; точность
  расшифровки при их соблюдении ещё не измерена — для этого нужен эталон: бумажные ЭЭГ с
  одновременной цифровой записью.
* Регламент не покрывает микрофильмы и экранные снимки цифровых систем (для последних нужен
  экспорт EDF, а не изображение).
