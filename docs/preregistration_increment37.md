# Пре-регистрация, инкремент 37: задний доминирующий ритм должен быть задним

> Зафиксировано до прогонов. Проверка регрессий: оценочная часть NMT и ds003775 уже
> использовались (инкременты 22–26, 34, 36), I-CARE — в инкременте 35.

## 1. Что меняется (`configs/thresholds.yaml`, `pdr_posterior_dominance_min: 1.0`)

На I-CARE (кома после остановки сердца) детектор ЗДР нашёл «ритм» (медиана 7 Гц) у пациентов
в коме, и правила в 22% записей оставались на «норме» (инкремент 35). Детектор требует только
настоящего спектрального пика 4–13 Гц над затылком. По определению (ACNS, 2021) задний
доминирующий ритм — **задний**: изменение — пик засчитывается, только если его мощность
(частота пика ± 1 Гц) над O1/O2 **не меньше**, чем над F3/F4. Иначе ЗДР «не выделен».
Порог 1.0 взят из определения, не подобран. ЗДР — также вход модели уровня записи, поэтому
меняется и её вход (там, где «ритм» не задний).

## 2. Проверки (`evaluation/prereg37.py`)

1. **NMT, оценочная часть** (185 записей; `neurolens routine eval`, текущий код) против
   сохранённого прогона инкремента 36 (`docs/increment36_nmt_eval.json`): потеря
   специфичности заключения ≤ 0.02 и потеря чувствительности ≤ 0.02.
2. **111 здоровых ds003775** («как есть», 64 электрода) против `docs/increment34_delivered.jsonl`:
   потеря специфичности ≤ 0.02 (≤ 2 из 111).

**Правило:** изменение сохраняется, если выполнены все три условия; иначе выключается
(`pdr_posterior_dominance_min: 0`).

Описание (не гипотеза — данные уже видены): I-CARE повторно (тот же отбор, тот же код
прогона) — чувствительность правил и заключения, доля записей с ЗДР; сколько норм NMT
потеряли ЗДР.

## 3. Воспроизведение

```bash
PYTHONPATH=src python -m neurolens.cli routine eval --workers 4 --out docs/increment37_nmt_eval.json
PYTHONPATH=src python scripts/run_ds003775_eval.py docs/increment37_ds003775.jsonl --workers 4
PYTHONPATH=src python scripts/run_icare_eval.py docs/increment37_icare.jsonl --workers 10
```

## 4. Ограничения

Критерий не проверяет реактивность (открывание глаз), второй признак ЗДР: меток проб в
данных нет. При усреднённом референте задний ритм частично переносится на лобные отведения —
критерий тогда мягче, а не строже.
