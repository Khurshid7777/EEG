Пре-регистрация: `docs/preregistration_increment56.md` (коммит 6c26882; три дополнения до получения
результатов описаны в самом документе). Скрипты: `scripts/run_covisleep_sleep.py`,
`scripts/run_nmt_fresh.py`, `scripts/select_nmt_fresh.py`. Результаты:
`docs/increment56_assess_covisleep.json`, `docs/increment56_assess_nmt_fresh.json`. Решения — D98, D99.

## Тест A. Сон на COVISLEEP (другой центр, другой прибор, пациенты с бессонницей)

92 ночи (запись `T1_29` исключена: открывалась до пре-регистрации), ошибок нет, 85 791 эпоха.
Путь продукта, модели заморожены по SHA-256.

| Метрика | Значение |
|---|---|
| **Каппа со сглаживанием** | **0.635** (95% ДИ по ночам 0.602–0.666) |
| Каппа без сглаживания | 0.605 |
| Прибавка сглаживания (парно) | **+0.031** (ДИ 0.026–0.036) |
| Точность / макро-F1 | 0.729 / 0.656 |
| Медиана каппы по ночам | 0.613 |
| Группа S (после long-COVID) / T | 0.654 / 0.626 |
| F1 W / N1 / N2 / N3 / REM (со сглаживанием) | 0.795 / 0.222 / 0.756 / 0.757 / 0.752 |

* **H1 (путь AASM): подтверждена** (каппа ≥ 0.60 и нижняя граница ≥ 0.50). Изменений в конфигурации нет.
* **H2 (сглаживание): подтверждена** (прибавка ≥ +0.005, нижняя граница > 0).
* Мой прогноз был 0.58–0.62 («ниже порога вероятнее, чем выше»); результат оказался выше. N1 действительно слабее
  (F1 0.22 против 0.43 на MGH): у людей с бессонницей много бодрствования и N1.
* Оговорка: это один центр и одна популяция; результат подтверждает включённое, а не расширяет область применения.

### Отклонения от плана (все зафиксированы в пре-регистрации до получения результатов)

1. Разбор файлов разметки: форматы времени и нумерации различались (39 файлов без даты, часть начинается с
   поздней эпохи, один без столбца `Epoch ID`, «Éveil»); разбор переписан по заголовкам, без просмотра предсказаний.
2. Выравнивание: предел «сдвиг ≤ 30 мин» исключил бы 40 из 92 ночей без причины (нумерация шла с более
   раннего начала); заменён сдвигом по времени и проверкой, что ≥ 90% размеченных эпох внутри записи.
3. Память: на двух 80-канальных записях процессы упали по памяти (OOM); чтение EDF получило фильтр каналов
   (`include`), результат на проверочной записи идентичен полному.

## Тест B. Специфичность заключения «норма / отклонения» на не открывавшихся записях NMT

997 нормальных записей NMT, не использованных ни одним инкрементом (список зафиксирован до первого запуска),
рабочая конфигурация без изменений; ошибок чтения нет.

| Показатель | Значение |
|---|---|
| **Специфичность** | **0.7192** (95% ДИ Клоппера–Пирсона 0.690–0.747); 280 ложных «отклонений» |
| Только правила / только модель | 0.735 / 0.719 |
| Доля пограничных | 40.8% |
| < 2 / 2–11 / 12–17 / 18–59 / ≥ 60 лет | 0.670 / 0.751 / 0.676 / 0.722 / 0.738 |

* **Правило решения:** 0.65–0.72 → вердикт остаётся, число этого теста идёт в текст с пометкой «ниже цели».
  Результат 0.7192 попадает ниже порога на 0.0008 — это в пределах шума (ДИ ±0.03), но правило применено как записано.
  Ожидание (0.74–0.79) не оправдалось: заявленное 0.79 было оптимистичным, как и предполагалось в находке F1.
* Заметно ниже среднего — дети до 2 лет (0.670) и подростки (0.676); интервалы широкие (n = 91 и 108).
* **Чувствительность этим тестом не проверена:** свежих аномальных записей нет. Остаётся открытой; нужен другой набор
  (NMT-4K, Zenodo 21405022, доступ по запросу).
* Тот же центр, что и разработка: это проверка воспроизводимости на новых записях, не внешний центр.

### Что изменено в продукте

`configs/impression.yaml` получил `fresh_specificity`, `fresh_ci95`, `fresh_n`, `fresh_below_target`,
`independent_specificity`. Текст заключения (RU/UZ) теперь: результат свежего теста с ДИ и пометкой «ниже целевых 0.72»;
числа оценочной части NMT (0.79 / 0.80) с пометкой, что пороги подбирались по этим данным; специфичность на независимых
центрах 0.96–1.00; чувствительность вне NMT не измерена. Без новых полей поведение прежнее (тест
`test_fresh_specificity_leads_the_validation_text`). Закрывает находку F1 аудита.

## Вывод

Сон на стандартном монтаже подтвердился на втором независимом центре (0.635). Заключение «норма / отклонения» на новых
записях того же центра работает хуже, чем заявлялось (0.72 вместо 0.79); формулировка в отчёте исправлена. Чувствительность
вне оценочной части NMT остаётся неизмеренной.
