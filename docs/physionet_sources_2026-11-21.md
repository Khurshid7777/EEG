# Другие источники PhysioNet для NeuroLens (поиск 2026-11-21)

Метод: перебор открытого S3-зеркала `physionet-open` (256 баз) + тематический поиск на physionet.org (eeg, sleep, seizure, anesthesia, ICU и др.; ~106 уникальных баз). Размеры — по листингу S3; доступ и описание — по странице базы. Содержимое файлов не открывалось, поэтому оценки полезности — гипотезы, не результаты.

## Уже использованы в проекте
sleep-edf(x), chbmit, siena-scalp-eeg, i-care (606 пациентов), hmc-sleep-staging, challenge-2018 (300 из ≈1000), psg-ipa, ucddb, capslpdb (инкремент 13b), eegmmidb.

## Рекомендация
1. Автономно: ничего с высокой отдачей на открытом PhysioNet не осталось. Если нужно, на `eegmat` можно сделать дешёвый дополнительный тест специфичности (36 здоровых), но он добавит мало к 111 + 29 + 95 уже проверенным нормам.
2. Запросить доступ: `jsmf-access` (restricted; требует заявки) — единственный новый источник с реальной пользой для наркозных состояний.
3. `slpdb` как ещё один центр стадировщика имеет смысл только с оговоркой про разметку R&K.
